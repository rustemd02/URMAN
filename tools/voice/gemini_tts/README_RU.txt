КАР УРМАН — текст в радиоэфир

Быстрый старт на Mac
1. Распакуй архив в обычную папку.
2. Создай Gemini API key в Google AI Studio: https://aistudio.google.com/app/apikey
3. Открой api_key.txt и вставь ключ одной строкой. Не добавляй кавычки или подписи.
4. Открой episode.txt и замени пример своим сценарием. Сохрани файл в UTF-8.
5. Дважды щёлкни RUN_MAC.command. Если macOS спросит подтверждение, выбери «Открыть».
6. Готовый radio.wav появится в этой же папке.

Первый запуск требует Python 3.10 или новее и интернет: скрипт сам создаст локальное окружение и установит библиотеку. При следующих запусках снова открывай RUN_MAC.command.

На Windows можно запустить RUN_WINDOWS.bat. Нужны Python 3.10 или новее и интернет.

Формат сценария
Каждую новую реплику начинай с одной из этих меток:

ВЕДУЩИЙ: Текст ведущего.
РАИСА АПА: Текст Раисы апа.

Пустые строки можно оставлять. Длинную реплику можно продолжать со следующей строки. Можно добавлять моментальные вокальные теги прямо в реплику, например <sigh>, <short pause>, <laugh>. Для наилучшего распознавания используй английские названия тегов.

Скрипт сам назначает голоса и постоянные характеры, отправляет диалог в conversational mode и сохраняет WAV. JSON вручную писать не нужно.

Важно
• В api_key.txt хранится секретный ключ обычным текстом. Не отправляй файл или архив с ключом другим людям и не публикуй его.
• Текст сценария отправляется в Gemini API для синтеза речи.
• Gemini официально указывает русский и крымскотатарский среди поддерживаемых языков; казанский татарский отдельно в опубликованном списке не указан. Произношение татарских слов в примере может отличаться от ожидаемого — послушай короткий фрагмент перед выпуском.
• Если в сценарии ошибка, скрипт покажет её в окне. При проблеме с ключом проверь, что вставил действующий Gemini API key без лишних символов.
