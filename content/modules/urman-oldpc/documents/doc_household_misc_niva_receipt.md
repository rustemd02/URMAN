# Квитанция

Нива: заменить ремень, проверить масло, не слушать Фаниса про «ещё походит».

Покупки:

- свечи;
- провод;
- чай;
- батарейки для фонаря;
- два пакета сахара.

Приписка Гөлсинә: «Мансур, не храни важные бумаги вместе с машиной».
