# Старые страницы: 2010–2012

## Из новостей
В ДК принимают фотографии с праздника. Пожалуйста, подписывайте конверты. Чужие снимки без разрешения владельца не публикуем.

Для стенда нужны подписи к семейным фотографиям, а не только фамилия того, кто принёс. Если точный год не помните, оставляйте место пустым.

## Гостевая книга
Гость из Казани: Сайт долго открывался, но фотографии посмотреть успел. Дома всё те же, только заборы другие.

Ответ редактора: Есть снимки у хозяев. На сайте не все: спросим разрешение, потом добавим.

Гость: Передайте салам нашим.

Ответ редактора: Передали. Приезжайте.
