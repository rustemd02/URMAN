# Антресоль: три коробки из-под обуви

Первая коробка: «ДАЧА. 1990-е. ПОСЛЕ 2000 — НЕ СМЕШИВАТЬ». Внутри снимки у печки, у мотоцикла, у ворот.

Вторая: «ГОРОД. ПИСЬМА ЖДУТ РАЗБОРА». Одно фото поверх остальных: два мальчика у забора, старший показывает младшему что-то на ладони. На обороте шариковой ручкой: «Марат учит Айдара находить дорогу по жердям. Оба довольны».

Третья коробка не подписана. Судя по пыли, её не открывали дольше, чем первые две. На торце, старым карандашом: «разобрать зимой».

Зимой, судя по всему, никто не торопился.
