# Сводная страница внутреннего учёта

Ведена одним почерком, но явно позже основных тетрадей — чернила другие.

Категории перечислены столбиком, против каждой — счёт по десятилетиям:

«Нарушение срока»: 1960-е — 1; 1970-е — 3; 1980-е — 2; 1990-е — 2; 2000-е — 1.

«Уход»: по единицам в каждом десятилетии, без закономерности.

«Граница / ответил»: 1960-е — 0; 1970-е — 1; 1980-е — 2; 1990-е — 0; 2000-е — 1.

Ниже, без категории, просто строка: «Не бывает так, чтобы долго не было».

Сводка на этом обрывается. Объяснений нет, и не похоже, что они предполагались.
