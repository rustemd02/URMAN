# Реестр дома, приписка

«Приезд: внук, А. Ожидается к лету, приехал раньше — хорошо.

Комната: та же. Постелено.

Стол: не трогать. По бумагам сам разберётся, если станет надо. Провод длинный ему протянуть, чтобы не сидел в темноте.

Ключ от этой машины: оставить на месте, где всегда. Не прятать и не показывать. Кто ищет — тот найдёт; кто не ищет — тому не надо».

Ниже, другой рукой: «Допуск — да. По дому всё можно. По бумагам — читай. Спрашивать — спрашивай меня, не деревню».
