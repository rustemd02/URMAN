# Надписи у дорожки
С дорожки читаются два соседних имени.

**Габдулла Сабиров**  
**1938–2009**

**Наҗия Сабирова**  
**1941–2021**

Памятники установлены в разные годы; снег лежит у оснований. Для чтения не нужно заходить за ограды или трогать вещи.

Здесь нет рассказа о работе, школе или празднике. Если фамилия знакома по другой записи, её ещё нужно сопоставить с полным именем. Одного соседства могил для вывода о родстве недостаточно.
