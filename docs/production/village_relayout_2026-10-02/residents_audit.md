# Жители: визуальный аудит — 2 октября 2026

Срез исполнения по поручению автора «жители какие-то странные». Работа ограничена
существующими 33 фоновыми жителями; новые жители, реплики, квесты и распорядки не добавлены.
Стабильные entity/character IDs, greeting/speaker/turn сохранены.

## Интеграция

- Новый partial: `game/scripts/AuthoredWorldDirector.Residents.cs`.
- Точка вызова: `ConfigureResidentPresentation(character, parameters)` в `case "npc"`
  `AuthoredWorldDirector.BuildObject`, после Attach, перед PlayClip/RegisterRoutine.
- Для прочих NPC без `residentAppearance` метод сохраняет прежнее чтение `scale`.
- Материалы одежды получают существующий `PainterlyMaterialLibrary.ForColor(...,"cloth",sheltered:true)`;
  общий character kit и его кэшированные материалы не меняются.
- Корень персонажа содержит meta `residentAppearance`, `residentPresentationScale`,
  `residentPresentationPolicy`, доступные для native QA.
- `tools/world/generate_residents.py` сохраняет проверенные kit/scale/residentAppearance по
  стабильным ID; новые позиции берёт из свежей физической съёмки. Для новых ID выбирает
  соответствующее существующее зимнее семейство. Свежая геометрия требует свежего spot-check.

## Выполненные проверки и границы

1. Прочитан GLB JSON реального `urman_character_kit_v2.glb`: все используемые prefix имеют
   body/clothing/boots/headwear/LOD0; семьи выбираются существующим human-v2 адаптером.
   Анимации стояния/разговора/сидения/работы берутся из действующего AnimationCatalog.
2. JSON parse; все 33 `position` совпадают с `schedule[0].place`; IDs/characterId/
   greeting/speaker/turn сверены до/после изменения.
3. Статическая проверка 31 стоящего/работающего человека против 14 870 transformed
   mesh AABB из актуальных open-part/far-bank parcel/prop GLB. Объём человека шириной
   0,64 м и высотой `1.65*scale`, низ 0,15 м; исключены низкий настил, roof/snow/ground,
   декоративные рейки/пикеты. До переноса найдены два жителя у ворот; после переноса
   пересечений с включёнными геометрическими объёмами нет. Это не physics proof:
   деревья/снег, коллизии, процедурная геометрия public buildings и seated poses требуют
   живой проверки, консервативный AABB не заменяет точную сетку.
4. Build/import/smoke/capture не запускались отдельным исполнителем; сериализует root.
   `graphify query` был запрошен первым для codebase-вопроса, но executable отсутствует
   (`command not found`); использованы действующие source/data/GLB.
