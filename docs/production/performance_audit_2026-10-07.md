## Проверенный пакет: временные массивы физических запросов

В `VehicleController` устранены четыре пропущенных места освобождения
Godot-массивов, ранее остававшихся финализатору:

- `ConstrainSteering`: исключения на каждый физический такт управления Нивой
  или мотоциклом; один массив на вызов, включая ранний возврат при препятствии.
- `VolumeOverlaps`: отдельные исключения для копыт и нижних частей ног лошади.
  Освобождаются только новые массивы, базовый массив принадлежит вызывающему.
- `PlacementOverlaps`: временные исключения общей проверки парковки/позы.
- `ValidatePhysicalPlacement`: массив результатов после проверки парковки,
  включая отказ по первому пересечению.

Использован существующий `(Godot.Collections.Array)typed` / `using` шаблон.
Формы, маски, порядок, число и результаты запросов не менялись. Это сокращение
отложенного освобождения native-ресурсов, не устранение цены самой физики.
Прирост FPS и величина влияния на финализатор не измерены.
