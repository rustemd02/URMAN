# Пак для внешнего art-ресета УРМАНа — что внутри и как этим пользоваться

Собрано: 2026-10-07.
Назначение: дать внешней модели (GPT 6 Pro в чате/проекте ChatGPT) всё необходимое, чтобы она
провела полномасштабное исследование визуала игры и выдала **handover для Codex**, выполнение
которого убирает «иишность» картинки.

---

референсных фотографий в паке нет. Кадры сконвертированы в JPEG q88 с сохранением исходного
разрешения. Основной пак: **177 кадров + 11 контактных листов = 41 МБ**; дополнительный набор
маршрута: **44 кадра = 8 МБ**.

## 2. Как это загрузить в ChatGPT

1. Создай **проект** (Projects) в ChatGPT — так кадры живут в «знаниях» проекта и модель видит их
   во всех чатах проекта.
2. Загрузи в проект:
   - папку `screenshots/` (или архив `URMAN_visual_pack_for_GPT.zip`);
   - файлы `attachments/APPENDIX_*.md`;
   - файл `00_PROMPT_FOR_GPT_RU.md`;
   - при желании — `screenshots_extra/08_route_moments/` (44 кадра маршрута) из архива
     `URMAN_visual_pack_EXTRA_route_moments.zip` и индекс `03_SCREENSHOT_INDEX_EXTRA_RU.md`.
3. В новом чате внутри проекта вставь текст `00_PROMPT_FOR_GPT_RU.md` целиком и запусти.
4. Попроси заполнять `01_HANDOVER_TEMPLATE_FOR_CODEX_RU.md`. Если ответ не влезает — проси
   продолжать по частям с сохранением нумерации.
5. Готовый `HANDOVER_FOR_CODEX_VISUAL_RESET.md` положи в репозиторий (например, в
   `docs/production/ai_visual_reset_2026-10-07/`) и отдай Codex как отдельное поручение.

## 3. Важно: репозиторий приватный

Проверено 2026-10-07: `https://github.com/rustemd02/URMAN` отдаёт **404** анонимному
пользователю — репозиторий приватный. Значит, «просто дать ссылку» недостаточно: GPT по ссылке
ничего не увидит. Три рабочих варианта:

1. **Коннектор GitHub в ChatGPT** (если он доступен на твоём тарифе): подключить и выдать доступ
   к приватному репозиторию. Наиболее чистый путь — модель читает код напрямую.
2. **Временно сделать репозиторий публичным** на время исследования и вернуть приватность после.
3. **Работать без кода.** GPT использует кадры + приложения А–Е. Приложение Г (карта
   рендер-пайплайна) и Приложение Е (инвентарь файлов) специально сделаны так, чтобы модель могла
   формулировать задачи с точными путями, даже не видя всего кода. В этом случае промпт требует
   помечать утверждения о коде как предположения.

В любом случае в промпте уже прописано: если доступа нет — GPT обязана сказать это первой строкой
и продолжать с явными допущениями, а не выдумывать содержимое файлов.

## 4. Что должно получиться на выходе

Один документ `HANDOVER_FOR_CODEX_VISUAL_RESET.md` по структуре из шаблона:

- диагноз, почему игра выглядит как «нейрослоп», привязанный к номерам кадров и файлам;
- целевой образ «ручной работы с душой» + арт-библия;
- разбор SOTA/AAA/инди-референсов: что взять как принцип, что не брать;
- 8–10 фаз работ, начиная с «Фазы 0 — фундамент»;
- 40–150 карточек задач для Codex, каждая с файлами, шагами, критериями приёмки, способом
  проверки кадром и списком «чего делать нельзя»;
- anti-slop протокол и требования к верификации;
- риски и вопросы, требующие решения автора.

Ключевое требование к результату: **Codex должен уметь начать работу, не задавая уточняющих
вопросов** (кроме списка вопросов автору в конце документа).

---

## 5. Как проверить, что документ получился хорошим

- Каждый крупный вывод ссылается на номера кадров и пути к файлам.
- Ни одна задача не сформулирована как «улучшить освещение»/«сделать красивее».
- Есть Фаза 0 — правила и проверки, без которых слоп вернётся.
- Ни одна задача не нарушает ограничения проекта: без DOF/motion blur/виньетки/хроматики/LUT,
  без нового рендера, без «поднять saturation» и «затемнить экран», в рамках бюджета
  (119–145 FPS на M4 Pro, ~65–71 тыс. мешей), без нарушения культурных правил.
- Для каждой задачи указано, какой кадр снять до и после.
- Есть раздел «чего достичь нельзя» и раздел «вопросы автору».

## 6. Пересборка пака

Если понадобится обновить кадры:

```bash
python3 _research/build_pack.py                 # пересобрать screenshots/ из репозитория
python3 _research/build_contact_sheets.py       # пересобрать контактные листы
python3 _research/build_index.py                # пересобрать 02_SCREENSHOT_INDEX_RU.md
python3 _research/build_extra_route.py          # пересобрать screenshots_extra/08_route_moments/
```

Список кадров и подписи к ним — в `_research/build_pack.py` (массив `ITEMS`),
описания моментов маршрута — в `_research/build_extra_route.py` (словарь `DESC`).
