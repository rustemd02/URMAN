# Татарский слой: что уже реализовано — 2026-10-04 (ACT1-LANG.4/.5/.APPLY/.ADAPT)

Проверено по коду и контенту; игра не запускалась. Карточки `.1/.2/.3/.6/.7` уже
completed; здесь — фактическое состояние четырёх открытых.

## Три уровня и переключение (LANG.4, LANG.5)

- Уровень хранится как `TatarLanguageLevel` со значениями `none / some / fluent`
  (`FirstPersonController.cs:50`), то есть «нулевой / продолжающий / хороший».
- **Ручное переключение есть:** `SettingsUi.cs:417-434` строит строку
  `TatarLanguageLevelRow` с `OptionButton` («Не знаю», «Немного знаю», далее третий
  уровень), значение сохраняется в `settings.TatarLanguageLevel` и применяется через
  `SetTatarLanguageLevelAsync`. Это **настройка, а не состояние расследования**, поэтому
  смена уровня не сбрасывает прогресс, источники и найденное — критерий LANG.5 выполняется
  по построению.
- Калибровка в разговоре есть: сцена поездки в Ниве показывает текущий уровень
  («Татарский в разговорах: … Это можно поменять в настройках») и меняет его на месте
  (`Act1DemoRoot.PrologueNivaRide.cs:235,470-479`).

## Фактическая разница трёх уровней (LANG.ADAPT) — проверено по контенту

Механика: `CompiledCampaignRepository.ResolveText(textId, level)` берёт вариант
`{textId}.lvl-some` / `.lvl-fluent`, то есть уровень меняет **сам текст**, а не подсказку к
нему (`:316-325`).

Измерено в `content/modules/urman-chapter1/definitions.json`:

- **26 текстов** имеют оба варианта, и базовый текст есть у всех 26 (26/26).
- **Все 26 различаются формулировкой по всем трём уровням** — одинаковых нет (0).
- Распределение по сценам ровно такое, как требует единица карточки «одна сцена и повторный
  контекст»: **20 строк одной сцены** — `prologue-ride-bark-*` (замечания и вопросы бабая в
  поездке) и **6 строк повторного контекста** — `dialogue-*` (Гөлсинә, Мансур, Тимур).

Пример разницы (Гөлсинә): базовый — смешанная фраза с одним татарским словом; `some` —
русская основа с татарскими вставками и переводом в скобках («Утыр, җылын — садись,
согрейся»); `fluent` — полный татарский без подсказки («Утыр, җылын, балам. Кичен урманга
барырга ярамый — беләсең бит»). Это разница плотности и сложности, а не «одинаковый текст с
разными подсказками», который карточка прямо запрещает.

## Содержательная задача через татарское слово (LANG.APPLY)

- Раздел словаря на ПК существует: приложение `tatwiki` («TatWiki · Татарвики»,
  `OldPcUi.Apps.cs:502,611,628`), плюс сцены `evidence-tatarwiki-boundary` и
  `evidence-tatarwiki-reread` (`Act1DemoRoot.cs:1695-1702`).
- Самостоятельный ввод есть: `BuildGlobalSearch()` (`OldPcUi.Apps.cs:56`) с полем поиска и
  отдельным пустым состоянием (ранее проверено в UI-аудите).
- Что остаётся содержательным, а не техническим: связать конкретное татарское слово с
  **обязательным** результатом расследования (ранняя пара контекстов + один поздний ключ) и
  показать проход «контекст → вспомнить в книжке → ввод/поиск → полезный результат →
  применение». Механика для этого есть; решение о том, какой именно ключ обязателен, —
  авторское.

## Границы

Техническая часть (уровни, настройка, подстановка вариантов, словарь, поиск) проверена здесь.
Человеческая — понятность и уместность плотности татарского для каждого уровня — остаётся
`not-run`: она требует прохода, а не разбора данных. Ничего в контенте не менялось.
