# Пролог и экскурсия по деревне: разбор диалогов — 29.09.2026

Источник текстов: `content/modules/urman-chapter1/definitions.json` (`prologue-ride-bark-*`, `prologue-niva-*`).
Разбор сделан по запросу автора 29.09: татарский на здравость, точность перевода, длина и скорость чтения,
разметка под генератор речи. **Проверка носителем не проводилась и не заменяется этим разбором** — я не носитель,
так что «здраво» здесь значит «не нашёл ошибок при внимательном чтении», а не «подтверждено». Всё татарское остаётся
черновиком до отметки носителя (open_questions: OQ-LANG-PROLOGUE).

## 2. Что остаётся под вопросом (нужен носитель)

| Место | Сомнение | Уверенность |
|---|---|---|
| «чокыр» (овраг) | в говоре может быть другое слово (сай, елга буе); значение «яма/овраг» есть | средняя |
| «өске як» («верхняя часть») | понятно, но так ли говорят в деревне | средняя |
| «геройланма» | разговорное, образовано мной; возможно «герой булма» | низкая |
| «Түбән урам» | норма для «Нижняя улица» | высокая |
| «сишәмбе / җомга» с «икмәк» | дни недели и падежи проверить | высокая |
| «ут янмый» (свет не горит) | «ут» — огонь/свет, для лампочки говорят и «ут», и «свет» | средняя |
| уровень «some» | смесь русского и татарского намеренная (так говорят городские татары, переходя с языка на язык): нужен ли именно такой | решение автора |
| Тимур хәзрәт «ведёт свадьбы» | по-татарски «туйларны алып бара»; религиозную сторону церемонии не уточняем | решение автора |

## 3. Длина и скорость чтения

- Русская (основная) реплика: 60–136 знаков, читается за 4–7 секунд; субтитр держится не меньше 4,5 с и не больше 11 с,
  а при озвучке — длину клипа + 0,8 с.
- Татарские уровни (some/fluent) длиннее на 10–25% из-за подстрочника. Подстрочник — вторая строка меньшим шрифтом
  (если шрифт субтитра не разделён — задача UI: `ShowPrologueCaption` пока показывает одним абзацем).
- Очередь: реплики экскурсии стартуют не раньше окончания предыдущей (клип + 1,5 с), поэтому наложения нет.
- Общая нагрузка: 11 реплик за ~120 с деревенского участка = одна реплика примерно в 11 секунд; это больше, чем
  достаточно «дышащей» тишины между ними.

- `prologue-niva-answer-fluent`: «Юк, бабай, онытмадым! Татарча сөйләшәм».
- `prologue-niva-answer-skip`: (Промолчать и смотреть в окно.)

это правильная «нулевая» подготовка до задачи (обучение до применения), не тест перевода.

## 6. Разметка для генератора речи

Файл: `tools/voice/gemini_tts/speech_markup.json` (79 записей). Для каждой реплики: говорящий, сцена, язык, тон
(уходит в `speech_metadata`, не читается вслух), темп, паузы до/после (вшиваются в WAV тишиной), приоритет P0/P1/P2,
запасное написание `tts_text` для подбора произношения. Тексты в разметке не дублируются — берутся из `definitions.json`.

Порядок работы при бесплатном лимите (~10 запросов в сутки на модель):
1. `generate_prologue_voices.py --list --priority P0` — 25 реплик, без которых сцена теряет смысл;
2. затем `--priority P1`, потом всё;
3. изменившиеся тексты пересинтезируются сами (генератор сравнивает текст в `manifest.json` с текущим); сейчас
   устарели клипы почти всех реплик экскурсии;
4. после первого прослушивания — править только `speech_markup.json` (`tone`, `pace`, `tts_text`) и запускать с `--only`.

Ограничения: Gemini не заявляет казанский татарский среди поддерживаемых; ждите русский или тюркский акцент. Проверка на слух —
человеком; синтез остаётся превью и не закрывает AUDIO-011…013.
