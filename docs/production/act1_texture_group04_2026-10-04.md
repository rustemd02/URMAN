## Лицензия и происхождение — уточнено в инвентаре

Ни одна строка группы не называла лицензию, хотя карточка требует и её. При этом по
составу все 14 получателей — файлы самого проекта, а карты группы либо генерируются
(ImageGen), либо взяты из существующей проектной библиотеки, то есть внешних лицензий
внутри группы **нет**. Чтобы поле не оставалось пустым, в инвентарь добавлена явная
строка происхождения: для группы .04 лицензия проектная (URMAN/ImageGen), а для
импортированных носителей из других групп (например O06, A3-01) лицензию исходного
пака следует указывать в карточке носителя, а не считать её подразумеваемой.
Утверждение о лицензии сделано по составу получателей, а не по внешнему источнику.
