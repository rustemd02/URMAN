# ACT1-FOOTSTEP.1/.2 — диагностика и фикс лага шагов вне дороги (2026-09-20)

Метод: `act1_footstep_lag_probe` (headless, guard) — 1500 физических тиков
ходьбы от остановки `arrival` по улице и затем вне дороги; на каждом тике
записаны срабатывания шагов (`FootstepAudioController.StepTriggerCount`),
интервалы, скорость и меты CPU `SnowTrampleField`. Receipts:
`probe-before-fix.json`, `probe-after-fix.json`.

Диагноз по данным (до фикса):

- Каденс самих триггеров ровный: медиана 10 тиков (~0,55 м) на дороге и вне.
- Перестроение снега на главном потоке на каждый шаг: среднее 5,3–7,7 мс,
  пики 25,6–26,4 мс, до 196 402 перестраиваемых треугольников. На реальном
  железе это просадки кадровой частоты при каждом шаге и сдвиге окна —
  воспринимается как «звук шагов лагает» вне дороги (лес/дворы добавляют
  свою нагрузку поверх).

Фикс (ACT1-FOOTSTEP.2):

1. `SnowTrampleField`: потолок подразделения `MaximumDivisions = 20`,
   тяжёлое перестроение меша не чаще каждого второго штампа
   (`RefineEveryStamps`), скан накопленных штампов корректно учитывает
   отложенные обновления (`_refinedStampTotal`).
2. `FootstepAudioController`: каденс переведён из `_PhysicsProcess` в
   `_Process` — при просадках несколько физических тиков слипаются в один
   кадр и тиковый каденс сгущал бы шаги в один момент; накопление реального
   смещения по кадрам держит шаги равномерными по времени.

Результат (после фикса, тот же проб): пики 13,0–14,0 мс (−47…−49%),
среднее 3,0–4,3 мс, перестраиваемые треугольники ≤95 182 (−54%),
каденс не изменился (медиана 10 тиков). Границы: headless-замер CPU не
равен полному кадру с рендером; человеческое прослушивание остаётся
external/not-run. Смоки `act1_footstep_smoke_test`,
`first_person_step_smoke_test` PASS после фикса.

# ACT1-LEGS.1/.2 — походка при взгляде вниз (2026-09-20)

Фикс (`FirstPersonController.Body.cs`): фаза шага синхронизирована с
каденсом шагов (`GaitCycleMeters = 1,1 м` = 2 × интервал звука шагов; раньше
цикл 0,86 м давал постоянное проскальзывание стоп), амплитуда масштабируется
фактической скоростью, цикл продвигается только проекцией движения на
взгляд — стрейф больше не «лунная походка» вперёд, спина крутит цикл назад.

Приёмка: `gait_capture_probe` — 16 кадров ходьбы по плоской дороге с
взглядом вниз (`gait/gait_*.png`); последовательность просмотрена:
ботинки чередуются, подъём умеренный, экстремальных поз нет. Кадр
`player-movement/02_walking_lower_body.png` с задранными коленями — момент
подъёма на тестовый ящик (`TryWalkUpStep`), воспроизводится и до фикса.
Регресс: `act1_player_movement_smoke_test` PASS (подошвы у земли, капсула
целостна). Человеческая художественная приёмка остаётся external/not-run.
