# Татарский словарь — 2026-10-04 (ACT1-UI.6)

Проверено по коду, данным и шрифтам; игра не запускалась. Единица U2: «Татарский словарь;
один вид и его реальные состояния». Критерий: экран отличает услышанное/гипотезу/
подтверждение, источник и действие; поиск, пустая выдача, татарские глифы и возврат
работают; готовый реестр знания не переписывается.

## Что уже реализовано

Словарь — вкладка `JournalUi.Vocabulary.cs` того же экрана `JournalUi`.

| Требование критерия | Чем закрыто |
|---|---|
| Отличает услышанное/гипотезу/подтверждение | фильтр статуса `Все слова / Гипотезы / Подтверждено`; статусы слова приходят из эффектов `vocabulary.set-status` (6 интерактивов) и реестра на 12 слов |
| Источник | поле поиска прямо ищет «слово, значение или источник» (`Найти слово, значение или источник…`), источник показывается в записи |
| Поиск | `_wordSearch.TextChanged → FilterVocabulary()` |
| Пустая выдача | явное состояние: «По запросу и фильтру слов не найдено.» |
| Возврат | кнопка `Close` и Escape, с подсказкой `RefreshCloseHint()` |
| Реестр не переписывается | интерфейс только читает контент (`vocabulary` в `definitions.json`, схема `vocabulary.schema.json`); своих «улучшенных» значений UI не создаёт |

## Татарские глифы — проверено фактически

Проверены `cmap` всех пяти шрифтов проекта (`game/assets/fonts/*.ttf`): PT Sans Narrow
Bold/Regular и PT Sans Bold/Italic/Regular содержат **все** татарские буквы
`ә ө ү җ ң һ` и их заглавные варианты — отсутствующих глифов нет (717 символов в каждом
`cmap`, формат 4). То есть «татарские глифы работают» — не предположение, а проверенный
факт для используемых шрифтов.

## Действия и полнота

Словарь связан с реальными действиями: слова входят через настоящие задачи (поиск на ПК,
таблички, речь), а не отдельным «уроком». Правило из `gameplay.md` — не выдавать
сюжетную улику за открытие книжки или настройку языка — интерфейсом не нарушается: экран
показывает состояние слова, а не подменяет находку.

Техническая часть (состояния, поиск, пустое состояние, глифы, возврат, источник данных)
отделена от художественной/человеческой, которая остаётся `not-run`.
