# LEN01 — почему Акт I проходится за 5–6 минут вместо ~50

Дата: 2026-09-15. Срез: `main`, `fe3ae7e`. Аудит по §13 плана переработки.
Статус: **воспроизведено по данным репозитория; человеческий хронометраж не выполнялся** (в этой среде нельзя играть обычным управлением), и это не закрыто числами ниже.

## 1. Воспроизведение и измерения

| Величина | Значение | Источник |
|---|---|---|
| Скорость ходьбы игрока | **3,4 м/с** | `game/scripts/FirstPersonController.cs:19` (`WalkSpeed = 3.4f`) |
| Длина обязательного физического маршрута | **424,88 м** | физический walkthrough, `act1_first_person_walkthrough: PASS distance=424,88m` |
| Чистое время ходьбы по обязательному маршруту | **424,88 / 3,4 ≈ 125 с ≈ 2 мин 05 с** | деление двух величин выше |
| Весь авторский текст главы (русский, все реплики + подписи + UI-тексты диалогов) | **1 234 слова** | подсчёт только значений `translations.ru` по 233 записям `content/modules/urman-chapter1/definitions.json` |
| Диалоговых записей | 65 | там же |
| Обязательный документ | `arrival-photo-evidence.md` — **68 слов** | файл в модуле |
| Три сравнения — ядро расследования | **22 слова** (`compare-records-contradiction` 6, `compare-route-match` 8, `compare-voice-link` 8) | `definitions.json` |

Вывод-воспроизведение: при тихом чтении русского текста ≈180 слов/мин **весь** корпус главы — это ~7 минут чтения, если игрок читает вообще всё, включая необязательные реплики. Обязательная ветка использует малую часть этого корпуса, а 2 минуты из бюджета съедает ходьба. Итог 5–6 минут — не аномалия, а прямое следствие объёма: **авторского текста на 50 минут главы нет в принципе** (для 50 минут нужно порядка 6 000–9 000 слов обязательного чтения/прослушивания, то есть в 5–7 раз больше, чем написано сейчас во всей главе).

## 2. Карта причин (по убыванию вклада)

1. **Объём обязательного текста.** Вся глава — 1 234 слова; ядро расследования (три сравнения) — 22 слова. Никакая механика не даст 50 минут на таком корпусе.
2. **Обязательный маршрут один и короткий.** Приезд → дом → ФАП → возврат → зират → кромка, 425 м, одна улица. Нет второго цикла расследования, нет обязательного повторного визита с новыми знаниями, нет шлюза, который заставляет переосмыслить уже пройденное место.
3. **Финал закрыт, но коротким шлюзом.** Доступ к кромке требует подтверждённого знания о границе, `rinat.alerted` и завершённого бита — гейты есть (`scene/forest-approach` entryConditions), но проходятся за три коротких действия.
4. **Все 24 находки и 7 физических ветвей необязательны и ничем не вознаграждаются до финала** — по канону это верно (расследование не должно требовать тайников), но значит, что на основное время они не работают.
5. **Нет ритмических пауз:** ни одной сцены с длительной репликой, ожиданием, наблюдением или обязательным чтением документа на несколько абзацев.

## 3. Задачи исправления (зарегистрированы в `execution_backlog.json` как LEN01.1–LEN01.5)

- **LEN01.1 (автор):** карта битов обязательного пути с целевыми минутами на бит и планом, где текст нужен, а где — действие.
- **LEN01.2 (автор + контент):** расширить ядро расследования из трёх однострочных сравнений в цепочку из 5–7 шагов с перекрёстным чтением документов в разных местах; целевой корпус обязательного текста — 4 000–6 000 слов.
- **LEN01.3 (проверка, можно сразу):** убедиться, что каждый обязательный документ читается *полностью* (сейчас есть только счётчик открытия), и что повторное чтение с новыми знаниями даёт новую строку — это дешёвый способ удлинить цикл без нового текста.
- **LEN01.4 (проектное решение автора):** связать K из 24 находок с обязательным выводом, не ломая канон «расследование не требует тайников».
- **LEN01.5 (человек):** честный хронометраж обычного прохождения вслух с автором — только он закрывает LEN01, числа выше его не подменяют.

## 4. Что этот аудит не делает

Не пишет новый текст, не двигает финал, не добавляет механик EX01–EX14 (это отдельные карточки §13) и не объявляет время закрытым. Задача закрыта, когда авторский проход замерен и сравнён с целью — здесь нужна людская проверка.
