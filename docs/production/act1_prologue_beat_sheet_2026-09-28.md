# Beat sheet пролога Акта I — Кара-Урман, 28 сентября 2026

Единица N1 по ТЗ01 (`docs/tasktracker/review_2026-09-28/01_prologue_narrative.md`).
Порядок утверждён автором 28.09 (decision_log, два раунда): лесной флешфорвард →
затемнение и голос бабая → переднее пассажирское место Нивы, целый мост,
экскурсия и разговорная калибровка татарского → дом, чай → первые встречи/Алсу →
сон → ночная катсцена метели и обрушения моста → утренняя новость → расследование.
Автобус — предыстория встречи на остановке, без отдельной катсцены.

Для каждого бита: кадр/сигнал, действие игрока, знание до→после, skip/load,
состояние мира. Владельцы и точки переноса существующих ворот — в конце.

## Биты

### P1. Лес — будущее, увиденное неполно (флешфорвард)

- **Кадр/сигнал:** ночь, густой зимний лес у кромки (зона `kara_urman_night`,
  спавн forest-approach). Темнота, глубокие тёмные ряды стволов (мотив A01.1),
  редкие глазоподобные дупла. Тишина, скрип снега под ногами.
- **Действие игрока:** короткий управляемый проход по заданному коридору
  (~15–25 м, обычная ходьба; границы — сама чаща, без новых невидимых стен).
  В конце коридора — звук быстрых шагов рядом невидимого (панорамный шорох),
  резкий стинг, удар в чёрный экран.
- **Знание до→после:** до — ничего; после — только ощущение «в лесу что-то
  есть». Без имени существа, без Марата, без правила «не отвечай».
- **Skip:** Esc/пробел в любой момент → сразу чёрный экран + голос бабая.
  Пропуск не даёт знаний/предметов сверх просмотра.
- **Мир:** отдельная ночная зона; сюжетное состояние не движется (без
  knowledge/vocabulary эффектов); возвращения в этот лес в Акте I нет.

### P2. Чёрный экран, голос бабая (переход)

- **Кадр/сигнал:** полный чёрный экран; голос Мансура будит Айдара (титр
  «Мансур бабай: „Әй, уян, әбием көтә инде…“ — текст; звукозапись — внешний
  гейт). Пауза 1–1,5 с.
- **Знание до→после:** после — «я заснул по дороге, бабай за рулём, едем
  домой». Причина приезда — навестить бабая и әби после долгого отсутствия.
- **Skip:** пропускается вместе с P1 или отдельно (Esc).
- **Мир:** нет.

### P3. Нива — переднее пассажирское место, целый мост, экскурсия

- **Кадр/сигнал:** камера на переднем пассажирском сиденье существующей Нивы
  (видимый салон: руль-эталон, панель, руки бабая на руле — постановка на
  существующих ассетах). Машина едет по въездной дороге, пересекает **целый**
  мост через овраг (текущее состояние `Ravine` до метели), въезжает в деревню.
  За окном — узнаваемые места: кромка леса, река/овраг, дома, школа/ДК/ФАП/
  мечеть/магазин (транзитом), своротка к дому.
- **Действие игрока:** смотреть по сторонам (свободный обзор в пределах
  салона); 1–2 наблюдательных выбора («посмотреть на…») без права выйти.
- **Знание до→после:** узнавание топографии деревни (без новых сюжетных
  фактов); мост существует и проезжаем (важно для утра).
- **Skip:** да; после пропуска топография всё равно доступна обычной
  прогулкой.
- **Мир:** `village_day` до метели; мост цел; дорога связана.

### P4. Разговор о языке (калибровка) — в Ниве

- **Кадр/сигнал:** бабай шутливо: «Казанда татарча онытканмын әллә?» — бытовые
  реплики с выбором ответа (не тест перевода): «почти не помню» / «немного
  понимаю» / «говорю, но ржаво» + явная возможность пропустить.
- **Действие игрока:** 1–3 бытовых ответа; подтверждение предложенного уровня
  или ручная смена; настройка в меню остаётся приоритетным override для новой
  игры.
- **Знание до→после:** уровень `none/some/fluent` зафиксирован для новой
  сессии. Ни одного сюжетного факта, `confirmed`-слова или story-flag.
- **Skip:** пропуск → ручной выбор настроек или `none`.
- **Мир:** только профиль языка новой сессии; старый слот не пересеивается.

### P5. Двор и дом: чай, потом осторожно о Марате

- **Кадр/сигнал:** Нива останавливается у двора; бабай/әби встречают; чай за
  столом. Сначала бытовой разговор; после — пауза (поведением сцены, не
  ремаркой) и осторожная тема погибшего Марата.
- **Действие игрока:** присесть к чаю (E), бытовая реплика; личная вещь/фото
  Марата находится **действием игрока** в комнате (перенос
  `view-arrival-photo` сюда; см. перенос ворот), память «Казанский, не
  отставай» подтверждается осмотром вещи, а не входом в сцену.
- **Знание до→после:** до — «Марат погиб» (знал при отъезде из Казани);
  после — «обстоятельств я не знаю; бабай/әби говорят сдержанно»
  (`topic_marat_unresolved` из находки, не из катсцены).
- **Skip/Load:** пропуск чая сводится к короткому итогу; load после чая не
  повторяет сцену.
- **Мир:** вход в `scene/house` перенесён по причинности (см. ниже).

### P6. Первые встречи на прогулке (Алсу — один из первых)

- **Кадр/сигнал:** Айдар выходит во двор; на улице жители, включая Алсу.
  Алсу сама окликает Айдара (R054), без второго случайного мужчины.
- **Действие игрока:** свободная прогулка по доступной стороне; приветствия;
  первое содержательное знакомство с Алсу — её роль и вопрос о Марате.
- **Знание до→после:** версии о «несчастном случае»/«сердце» (граница знания
  Алсу: самого случая не видела); знакомство с адресной системой вскользь,
  одним примером (R023/R024).
- **Skip/Load:** обычные.
- **Мир:** `village_day`.

### P7. Сон и ночная метель (катсцена обрушения)

- **Кадр/сигнал:** затемнение при уходе спать; ночная катсцена: сильная
  метель (существующая ночная атмосфера + снег/ветер), мост через овраг
  рушится (смена состояния `Ravine`), звук обвала. Без играбельного квеста.
- **Действие игрока:** смотрит или пропускает (Esc).
- **Знание до→после:** «ночью была буря» — утром подтверждается миром.
- **Skip/Load:** состояние моста детерминировано прогрессом (сон), не фактом
  просмотра; load утром даёт сломанный мост.
- **Мир:** мост целый → обрушен; выезд закрыт видимой причиной; дальний берег
  закрыт для свободного исследования.

### P8. Утро: новость и последствия

- **Кадр/сигнал:** утренний свет; у двора бабай с радио/новостью (титр):
  ночью буря разрушила мост. Видимая перемена: мост обрушен, дорога на ту
  сторону перекрыта обломками.
- **Действие игрока:** выйти, осмотреть, продолжить расследование
  (существующие циклы Акт I).
- **Знание до→после:** причина изоляции понята; мотив остаться — семья и
  Марат, не побег.
- **Мир:** пост-метельное состояние — единый флаг прогресса
  (`bridge_collapsed`), сохраняемый; согласованные коллизии/обходы.
