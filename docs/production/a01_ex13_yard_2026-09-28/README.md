## ACT1-EX13 — первый образец цикла «служебный проход» (дом → двор → улица)

Реализованная цепочка на существующем участке (без новых зон):

1. **Заметил**: у нижней ограды двора — снежный намёт в служебном проёме
   (`ToolSnowPileServiceGap`), разработанный край у створки и authored-цепочка
   следов от улицы к боковому проёму.
2. **Выбрал путь/инструмент**: лопата на своём упоре у мастерской.
3. **Действие**: взять лопату обычным вводом → навести на намёт →
   «Расчистить снег в служебном проходе».
4. **Результат**: намёт исчезает, физический барьер снят, проход из двора на
   нижнюю улицу открыт в обе стороны; остаётся выметенный след. Короткий путь
   работает на обратном ходу.
5. **Следующая возможность**: у поленницы из-под сугроба виден кончик рукояти
   (вторая расчистка → топорик; покрывается carry-smoke).

Физическое доказательство: `URMAN_DISCOVERY_ROUTE_ONLY=rear-house` в
`act1_first_person_walkthrough_smoke_test` — 47,51 м реальным CharacterBody:
калитка → лопата (обычный ввод) → расчистка → барьер снят → проход туда и
обратно. `PASS loop=yard-service-gap ... ex13-shovel-clear-gap-open=true`.
Кадры: `frames_ex13_chain/`. Полный механический разбор (цельность custody,
save/load, отказы, фонарь) — `act1_carry_interaction_smoke_test` full PASS
(329 проверок). Обход двора `babai-side` — PASS 46,03 м; кадры
`frames_yard_loop/`.

Интерес/понятность живым игроком — **external/not-run**; записано честно.

(−35.06, −14.28)) не имеет обычного пешего доступа из двора в текущей
раскладке: авторский объём дома закрыл западный коридор (x≈−34.2), верстак
мастерской с трапом занял северную полосу, ограда задней границы кончается
столбом (−36.5, −3.1), а юго-восточная воронка между домом и нижней оградой

`act1-discovery-walk: BLOCKED leg=rear-minaret-view ... owner=ACT1-VILLAGE-COMPOSITION/R123`

Решение — преднамеренный повторный вход/проход в композиции двора
(ACT1-VILLAGE-COMPOSITION, R123), не потокайлинг хрупкой полилинии.

также воспроизводится на чистом HEAD (не из этого пакета).
