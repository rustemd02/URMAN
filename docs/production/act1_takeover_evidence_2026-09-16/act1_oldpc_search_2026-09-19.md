# ACT1-OLDPC-SEARCH — глобальный поиск (2026-09-19)

Задача: `docs/tasktracker/TASKS.md` ACT1-OLDPC-SEARCH; ТЗ `docs/tasktracker/03_oldpc_full_system.md` §2.
Основание: ACT1-OLDPC-SHELL, ACT1-OLDPC-CHAT, ACT1-OLDPC-HINTS.

## Что сделано

- **Точка входа (§2.1)**: кнопка «Искать везде» в строке поиска архива и поле с кнопкой
  «Найти» прямо в меню «Пуск». Десятого окна нет — лимит ТЗ «окон max 9» соблюдён, результаты
  живут в том же списке архива, а режим помечен строкой состояния «Искать везде · найдено: N».
- **Один запрос по четырём источникам (§2.2)**: доступные документы (заголовок + тело),
  **доставленная** история чатов (заголовок треда и уже полученные сообщения — сценарий,
  которого игрок ещё не видел, в выдачу не попадает), личные заметки Айдара и история
  браузера по читаемым названиям страниц (плюс документы, которые он реально открывал
  через браузер). Обычный поиск архива по-прежнему работает как раньше и выключает
  глобальный режим.
- **Правила нераскрытия (§2.3)**: закрытая запись не участвует в выдаче — её заголовок
  не появляется ни в одной строке; вместо этого список получает ту же невыбираемую строку
  «🔒 Закрытые записи», что и архив. Клик по результату идёт обычным путём: документ — через
  `IsOldPcDocumentAccessible`, чат — через гейты тредов, заметка — в редактор, страница — в
  браузер. Поиск сам не даёт знания (проверено сравнением состояния).
- **Ноль результатов**: «Совпадений нет. Переформулируйте запрос или попробуйте: …» и три
  термина-ключа. Сначала идут татарские слова, которые игрок уже встречал
  (`LearnedVocabulary`), затем термины подсказок (`pointsTo`), затем `suggestedTerms`
  доступных документов; термин — это ссылка, которая повторяет запрос тем же путём.
