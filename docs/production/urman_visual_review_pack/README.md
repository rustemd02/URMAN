проблем картинки вместе с изображениями-примерами, чтобы получить

## Ключевые требования заказчика (в порядке приоритета)

1. **Снег** — главное. Должен выглядеть как настоящий: пушистый, с рельефом
   (заструги, надувы, нечищеные обочины, глубокая целина), искрящийся на
   солнце, с проминанием под ногами. Сейчас — «белое полотно».
2. **Правдоподобие** — мир должен читаться как настоящая деревня, а не как
   набор примитивов: дорога как дорога (колея, очищенная полоса, навалы по
   краям), деревья как деревья (ветки, сучья, кора, снег на ветках), кусты
   как зимние кусты.
3. **Атмосфера аутентичного татарского авыла** — без хвойных «пальм» на
   улицах, с лиственными (берёза/липа/рябина/черёмуха/ива), плетнями,
   колодцем-журавлём, стогами, крашеными наличниками, дальним силуэтом
   минарета.
4. **Фоны и глубина** — больше недостижимых дальних планов (лесные полосы,
   силуэты деревни, гряды, растворяющиеся в морозной дымке), чтобы горизонт
   никогда не выглядел пустым.
5. **UI** — выглядит как реальный архивный журнал, но можно стильнее и
   целостнее.

## Ограничения проекта (обязательны к учёту)

- Стиль зафиксирован: **painterly low-poly 3D** (не фотореализм и не PS1).
- Технические запреты: никаких DOF/motion blur/вигнетки/хроматических
  аберраций, никакого «свечения всего кадра», никаких LUT-файлов.
- GPU-бюджет: 120–145 FPS на Apple M4 Pro при пол 30 — есть запас, но
  количество мешей уже 65–71 тыс., наращивать геометрию нужно осторожно.
- Культурный слой: ислам и татарские детали — уважительно, без орнаментного
  перегруза, тексты — только через проверку носителем.
