# A10 · лесные снежные откосы, 27 сентября 2026

`Grade_Kara_West` и `Grade_Kara_East` были видимыми приподнятыми сетками без собственного контакта. Теперь их вершины подогнаны к текущему физическому рельефу, торцы сходят к земле на 3 м, а отдельные `SurfaceSupport` используют те же треугольники. Базовый террейн и его единственная форма, нужная опоре копыт, не менялись. Правка не касается западного уличного откоса из чужого незакоммиченного пакета.

Проверено на текущей C# DLL: сборка 0 ошибок/предупреждений; защищённый FAP-path `exit0`, 119 проверок; защищённый лесной боковой маршрут `exit0`, 157,37 м обычным контроллером без телепорта и аварийного возврата. [Кадр с реальной камеры](kara_forest_left.png) и [receipt](act1_visual_review_receipt.json) сняты на Medium при ночном состоянии леса; это обзор места, а не доказательство шага по вершине каждого откоса.

Общий `act1_boundary_architecture` остаётся `exit1`: 1005 проверок, 437,99 м; единственный отказ — `MainStreetForwardWestFacade: no independently verified face for a physical approach`. Этот же фасад уже открыт в `ACT1-TECH.2.current_checkpoint` до данного пакета. Массовое добавление контактов всем `Grade_*` было отклонено: оно перехватывало физические пробы дощатой дорожки ФАПа. Остальные декоративные откосы, контакт ног непосредственно на двух лесных гребнях, видимые стыки и человеческая художественная оценка остаются открытыми.
