# A10 · западный край двора мечети, 27 сентября 2026

Капсула игрока шла из двора к видимой западной стене. Аварийный предел террейна останавливал её на X = −61, хотя стена находится около X = −62,5. За 90 физических кадров контроллер зарегистрировал 81 `EdgeClamps`: игрок упирался в воздух. [Кадр до](before_contact.png).

Только западный аварийный запас уменьшен с 3 до 1,5 м; пределы остальных сторон и геометрия стены не менялись. На той же позиции после C#-сборки (0 ошибок, 0 предупреждений) защищённый нативный запуск довёл обычный контроллер до `MosqueCollisionProxy` на X = −61,949 без clamp, на поверхности. [Контакт после](after_contact.png). Обратный ввод вернул игрока на X = −60,530 без clamp или восстановления после падения. [Кадр возврата](after_return.png). [Receipt с SHA](receipt.json).

Это локальная проверка двора, не всего периметра и не человеческая оценка. Плотность/силуэт тёмного леса за стеной на этих кадрах требует художественного решения автора.
