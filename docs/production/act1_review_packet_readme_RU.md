# Пакет для внешнего человека — Акт I УРМАНА

Эта папка самодостаточна: всё, что нужно для четырёх внешних проверок, лежит здесь,
репозиторий открывать не требуется. Номер сборки, контрольные суммы, управление и
совместимость сохранений — в `START_HERE_RU.md` рядом с этим файлом; он обновляется при
каждой сборке, поэтому конкретные значения здесь намеренно не повторяются.

## 1. Новому игроку (сеанс M10)

- Распаковать папку уровнем выше (`../macos/URMAN.zip`) и запустить `URMAN.app`;
  сборка без подписи, поэтому система может предупредить — это ожидаемо. Windows-архив
  (`../URMAN-windows-x86_64.zip`) на Windows ещё не запускался.
- Играть 45–60 минут без подсказок, начиная с «Новая игра»; отвечать вслух.
- Девять вопросов и что записывать — в `act1_m10_handoff_package_2026-09-14.md`
  (раздел 8) и в `START_HERE_RU.md`; наблюдателю доступны только вопросы «что ты
  пытаешься проверить?» и «как ты это понимаешь?», подсказка — не раньше третьей
  минуты затора.
- Вернуть: дословные ответы, длительность, места затора со временем, желание продолжить.

## 2. Татарскому языковому и культурному консультанту

- Открыть `act1_language_review_sheet_2026-09-14.md`: словарь, тексты с татарским
  переводом, русские строки с татарскими словами, документы. Лист обновлён после
  добавления двух вопросов и двух ответов (в том числе вопроса про «Шүрәле»).
- Заполнить колонки «Вердикт» и «Severity» (Blocker / Serious / Minor / Style).
- Отдельный список в конце листа говорит, что смотреть вне таблицы.
- Вернуть: заполненный лист или список замечаний в том же формате.

## 3. Диктору

- Открыть `act1_voice_recording_brief.md`: две реплики, по три дубля каждой,
  требования к файлам, имена файлов, права и кредит.
- Вернуть: WAV-файлы и сведения о правах по списку из брифа.

## 4. Художественная оценка

- Кадры в `frames/`: шесть персонажей крупным планом (11), интерьеры (12), кисти рук до/после (13),
  три фазы каждого персонажа (14; различие кадров там даёт и мировая анимация, поэтому движение
  персонажа подтверждается листом 21), шесть NPC после скина (24), и листы до/после: наличники (15),
  зимние деревья (16), ели (17), пол ФАПа (18), UI при 720p и крупном тексте (19), покачивание NPC (20),
  движение из клипа после скина (21), проезд камеры по улице (22) и живое событие деревни — кот идёт
  через двор, 180 кадров подряд с шагом 1/30 с (23). Оба анимированных WebP открываются в браузере
  или Preview. Это захваты харнесса: камеру выбирает он и событие известно заранее, поэтому они
  **не являются прохождением** и не заменяют видео обычной игры.
- Смотреть нужно глазами; автоматика проверяет только достижимость, движение костей и эффекты.
- Одна честная оговорка по листу 9 (UI): его кадр журнала снят до правки 2026-09-14,
  после которой неподтверждённые («услышанные») слова помечаются «(услышано)» с
  поясняющей строкой. Текущую формулировку подтверждают smoke-проверки
  (`journal_flow_smoke_test`, `act1_ui_readability_smoke_test`), а кадр обновится со
  следующей сборкой; письменная формулировка журнала в остальном не менялась.
- Вернуть: список замечаний с указанием кадра.

## Чего в пакете нет и почему

- Видео прохождения: оно требует человеческой игры, которой пока не было; прежние
  записи относятся к другим сборкам и за текущую не выдаются.
- Записей голосов: их предстоит сделать по брифу. TTS и «примерные» файлы как финал
  не принимаются.

## Открытые пункты по ассетам

- Клипы Idle/Tension рабочие: персонажи скинены (9 скинов, 542 скиненых
  примитива), движение подтверждено кадрами (лист 21).
- Хвойные у Кара: ярусы ослаблены, но стволы сосен из исходного CC0-ассета.
