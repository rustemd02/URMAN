## 0. Определение «дорогой картинки» — качество-бар

Каждое утверждение ниже — критерий приёмки. Кадр/экран считается готовым, когда
выполнены ВСЕ пункты чеклиста своей фазы и общего бара.

### 0.1 Общие принципы (проверяются на каждом ключевом кадре)

1. **Единство языка.** Одна «кисть» везде: одинаковая плотность мазка, один масштаб
   деталей, одна степень стилизации. Ни один объект не выглядит из другой игры.
   Запрещены смешения: фотореалистичный проп рядом с флэтовым, чистый procedural-шум
   рядом с живописной текстурой.
2. **Ценовая иерархия (3 ступени).** В каждом кадре читаются: светлое (небо/дальний
   план) → среднее (земля, стены) → тёмные акценты (оконные проёмы, подвалы стен,
   внутренние углы). Если все массы в одной узкой полосе яркости — кадр бракуется.
3. **Направленный свет.** Тёплый ключ + холодная заполняющая. Тени имеют направление.
   Объекты «сидят» на земле (контактная тень/юбка грязи), ничего не плавает.
4. **Вариация без хаоса.** Соседние одинаковые объекты (дома, заборы, деревья)
   различаются тоном/фазой, но в одной гамме. Тайлинг текстур не виден с 3 м на
   поверхностях до 30 м.
5. **Каждый эффект обоснован.** Для каждого постэффекта действует тест отключения:
   если выключение не ухудшает кадр — эффект лишний, убрать или ослабить. Glow живёт
   только на эмиссивах (окна, горизонт неба) и не мылит UI. SSAO только сажает объекты,
   не даёт «грязь» в щелях плоских поверхностей.
6. **Ноль огрехов.** Не допускается: швы текстур, заметный тайл, растянутые UV,
   z-fighting, дыры/щели геометрии, плавающие над землёй объекты, «плавающие» тени,
   мерцание теней при движении, алиасинг на контурах (лестницы на краях крыш/заборов),
   резкие смены качества между зонами, прострелы камеры.
7. **Иерархия внимания.** Максимальная деталь — там, куда смотрит игрок: передний план,
   интерактивы, hero-объекты (дом бабая и әби, старый ПК, ФАП). Фон спокойнее. Деталь
   не размазана равномерно.
8. **UI — часть той же книги.** Все экраны выглядят страницами одного архива: бумага,
   тушь, печать. Единые отступы, типографика, состояния. Ничего «дефолтно-годотовского».

### 0.2 Анти-паттерны «дешёвой картинки» (немедленный брак)

- bloom/свечение на всём подряд, SSAO-грязь, хроматические аберрации, вигнетка,
  motion blur, DOF (запрещены design_style, кроме редких сюжетных случаев);
- одинаковые клоны домов/деревьев идеальными рядами;
- шум вместо текстуры; видимый квадрат тайла на стене/дороге;
- полностью плоский пасмурный свет без направления;
- окна — наклейки среднего серого; крыша того же тона, что стена;
- UI: разностилевые панели, разные шрифты, дефолтные кнопки, текст вплотную к краям;
- «яркость вместо формы»: осветление там, где нужна геометрия или текстура.

## 2. Фазы (исполнять строго по порядку; каждая фаза = полный цикл проверки из §4)

### Фаза 0 — Базлайны «до» (0,5 ч)

- Снять полный capture 48 кадров + 5 UI-скринов (через act1_ui_readability) в
  `evidence/act1_prod_ready/baseline/`. Это опора всех пар «до/после».
- Зафиксировать FPS (benchmark).

### Фаза 1 — Текстуры (самый большой вклад; ~40% результата)

1. Дождаться/получить 19 новых файлов из параллельной задачи (12 семейств: трава,
   крыша×3, кора берёзы×2, кора сосны, листва берёзы×2, бревно×2, обои×2, ФАП-стена,
   орнамент-фриз, палас, чит-ткань, резное дерево — ТЗ: см. файл задачи Codex).
2. Промоушен существующих кандидатов v2–v6 для старых семейств: A/B-харнессом
   `eng/capture-texture-candidate-frames.sh` снять сравнения, выбрать лучшее на
   семейство (доски/земля/штукатурка/хвоя/камень/ткань), переключить маппинг в
   `PainterlyMaterialLibrary`.
3. Подключить новые семейства (масштабы-старт в ТЗ), направить меши (верджи→grass,
   крыши→roof, стволы по isBirch, кроны берёз→leaf_birch, пучки травы→grass 0.25,
   интерьеры по зонам, этника — ТОЧЕЧНО: фриз на 1–2 объекта, резьба на hero-дом).
4. Прогнать полный capture. Осмотреть ВСЕ 48 кадров по чеклисту §0.1 (пункты 1, 4, 6).

DoD: ни одна крупная поверхность ни в одном кадре не выглядит голым цветом или шумом;
берёзы читаются берёзами; крыши отличимы от стен по материалу; трава — не ковёр-шум;
тайл не виден; этника присутствует ровно в отведённых местах.

### Фаза 2 — Материал-шейдер (перенастройка `PainterlyMaterialLibrary`)

1. Баланс: текстура доминирует — `texture_strength` 0.82→0.95 (текстура несёт тон
   и рисунок, base_color — лёгкий тинт ±15%).
2. Вертикальный градиент в шейдере: затемнение ×0.85 у земли (y<0.4 м) → ×1.0 к 3 м
   для фасадов/заборов/деревьев (грязь внизу — заодно решает «посадку»).
3. Per-instance вариация: детерминированный (от origin) hue-джиттер ±8° и sat ±5%
   для домов/заборов/крон; соседи-клоны исчезают.
4. Макро-пятна 2–4 м (низкочастотный шум в шейдере) — длинные стены/поля
   перестают быть однотонными.
5. Фасады: проекция текстуры по мировой вертикали (доски горизонтальны), не triplanar.

DoD: main_street_depth — соседние дома различимы тоном; 30 м стены не однотонные;
забор не выглядит одной палкой, размноженной копипастом;FPS не просел (benchmark).

### Фаза 3 — Свет, ценовая структура, пост-калибровка

1. Day-зоны: тёплый низкий ключ — цвет солнца ~`ffd9a8`..`ffe0b0`, энергия ↑ с 1.04
   до 1.35–1.5, угол ниже (−38°..−45°), shadow opacity 0.30→0.42; ambient холоднее
   (`9fb0b8`-семейство) и слабее (0.84→0.70). Небо остаётся бледным — контраст
   «тёплое на холодном» делают поверхности, не небо.
2. Окна: стекло к почти-чёрному (albedo ≤ 0.15), тёплый emissive только на
   авторизованных окнах (дом бабая, редкие на улице) — стабильное свечение.
3. Крыши: семейство тонов на 1 ступень темнее стен; контраст стены/крыши проверить по кадрам.
4. Пер-зонная калибровка поста (8 зон × кадр): для каждой зоны проверить — небо не
   пересвечено, тени без «грязи», glow только на эмиссивах, AgX не съел насыщенность
   (компенсация в Adjustments saturation/contrast по зоне), туман дальнего плана
   тёплый серый ≠ цвет неба на 1 ступень.
5. Тест отключения каждого эффекта (glow/ssao/adjustments/fog по одному): выключение
   должно ухудшать кадр; иначе — ослабить/убрать.

DoD: 6 ключевых кадров (arrival_forward, main_street_depth, babai_yard_forward,
zirat_depth, kara_approach_forward, fap_interior_forward) проходят §0.1 п.2,3,5;
UI-readability PASS (bloom не мылит текст).

### Фаза 4 — Палитра китов (Blender-генераторы + реэкспорт)

1. Таблицы цветов домов: тёплая охра/побелка как база (3–4 тона стен), редкие
   приглушённые сине-зелёные акценты только на ставнях/наличниках/дверях (не более
   1 акцентного дома на 3–4); крыши — 2 тона (шифер-серый, выцветший металл).
2. Растительность: свежая жёлто-зелёная трава против глубоких холодных елей;
   берёзы — светлая крона + белая кора (самый светлый вертикальный элемент улицы).
3. Реэкспорт GLB, `./eng/verify-asset-registry.sh` PASS, capture.

DoD: цветовая карта улицы (все дома в одном кадре main_street_left/depth) выглядит
намеренной: читаются 3–4 тона стен + акценты; никакие два соседних дома не совпадают
по паре (стена+крыша); зират монохромнее улицы, кара — холоднее всех.

### Фаза 5 — Земля и контакты

1. Дорога: тёмная влажная кромка (текстура/декаль), колеи.
2. Трава: макро-пятна через `vertex_pigment` (уже в шейдере) с масштабом 6–10 м.
3. Обочины: осветление кончиков (в текстуре grass).
4. Посадка: юбочка грязи/травы у цоколя каждого дома и вдоль заборов (mesh-skirt
   или тёмный градиент из Фазы 2) — ни один объект не «висит».

DoD: в babai_yard_depth, main_street_left, zirat_depth каждый дом/забор/дерево имеет
видимый контакт с землёй; дорога имеет читаемую кромку; травяные поля неоднородны
пятнами (видно на любом кадре с травой ≥ трети экрана).

### Фаза 6 — Силуэтные обвязы (Blender, медленно; по одному киту за итерацию)

1. Крыша: свес 0.25–0.4 м, толщина полотна, конёк-брус.
2. Стены: угловые доски, подоконники, чуть выпирающие наличники (0.03–0.05 м).
3. Дворы: печная труба на части домов, калитка с диагональю, колодец-жёрлов.
4. Цикл на каждый кит: генератор → blend → GLB → verify-asset-registry → build →
   walkthrough → capture → осмотр.

DoD: на контровом свету (солнце за домом) силуэт читается как «дом с крышей»,
не коробка; у окон есть глубина (наличник ловит свет); зерно capture-сравнения
сохранено в evidence.

### Фаза 7 — Жизнь (ветер)

1. Мировой time-параметр в painterly-шейдере; вершинное покачивание крон (амплитуда
   0.05–0.12 м, частота ~0.3 Гц, фаза от origin) и травы-пучков (0.02–0.04 м).
2. Отключение при reduced motion (существующий accessibility-контракт).

DoD: 3 кадра во времени или 10-с видео: кроны/трава движутся неоднородно (не синус
всем миром); при reduced motion мир статичен; walkthrough/benchmark PASS.

### Фаза 8 — Анти-артефактный аудит (перед UI, после всех мирных фаз)

Полный проход по 48 кадрам + 5 интерьерным точкам с чеклистом (на каждый кадр):
- [ ] швы/тайл текстур не видны;
- [ ] нет растянутых UV (искажение рисунка на скатах, торцах);
- [ ] нет z-fighting (мерцание совпадающих плоскостей: дороги/кромки/окна);
- [ ] нет щелей геометрии (стыки стена/крыша/цоколь, пороги дверей);
- [ ] все объекты сидят на земле (нет висящих заборов/деревьев/камней);
- [ ] тени стабильны (нет пульсации на границах);
- [ ] нет алиасинга-лестниц на контурах (крыши, заборы) — при необходимости MSAA 2x→4x
      в quality-профиле (проверить FPS);
- [ ] переходы зон без визуальных разрывов (двери, пороги);
- [ ] гистограмма кадра не в одной полосе (ценовая структура).

Каждый найденный дефект: запись (файл/кадр/место/скрин) → фикс → перезахват этого
кадра → закрытие. Цикл до нуля дефектов.

DoD: 48/48 + 5 интерьеров чистые по чеклисту; список дефектов с фиксами в карточке.

### Фаза 9 — UI-пасс (10 экранов)

Единый скин «бумага/тушь/архив» поверх существующих сцен
(`journal_ui.tscn`, `document_ui.tscn`, старый ПК, диалог, меню):

1. Общая рамка: бумажная фактура панелей (та же текстурная база, что документы),
   тушевые линии/углы, спокойные тени; шрифт единый с поддержкой ә, ө, ү, җ, ң, һ.
2. Состояния всех интерактивов: normal/hover/pressed/focus(gamepad)/disabled —
   единые, заметные, но не кричащие; фокус-кольцо обязательно (навигация падом).
3. Анимации: открытие/закрытие 150–200 мс, лёгкий сдвиг+fade; без пружин и резины.
4. Старый ПК: внешние хромы окон привести к той же бумажной рамке, внутренности
   остаются Win98-like (контраст «архивная бумага вокруг, старая система внутри» —
   сознательный приём).
5. Субтитры/prompt: та же типографика, безопасные поля, не перекрывают интерактив.
6. Проверка в 2 разрешениях (1280×720, 1920×1080) на всех 10 экранах.

DoD: матрица 10 экранов × 2 разрешения в evidence; все экраны в одном языке;
UI-readability smoke PASS; татарские глифы рендерятся во всех экранах с текстом.

### Фаза 10 — Финальная заморозка

1. Полный capture 48 + UI-матрица + видео-фрагмент ветра (2–3 точки маршрута).
2. Пары «baseline Фазы 0 → финал» по всем ключевым кадрам в evidence.
3. Benchmark: floor 30 с запасом; quality-профили (high = MSAA+полный пост,
   low = без triplanar — уже есть) не разъезжаются по стилю.
4. Карточки в ledger по фазам, `git diff --check`, graphify update.
5. Человеческий art-gate: висты и пары на ревью; без него план не закрыт.

## 3. Правила для исполнителя (обязательны малой модели)

1. Одна фаза — один полный цикл проверки (§4). Не накапливать несколько фаз до проверки.
2. Никаких новых систем рендера/UI-фреймворков; правки в существующих владельцах.
3. Любая правка материала/света/палитры сопровождается кадром до/после в evidence.
4. Если шаг непонятен — сделать минимальную безопасную версию и показать кадр,
   не додумывая контракт самостоятельно.
5. Числа в плане — стартовые; финальные подбираются по кадрам, с фиксацией в карточке.
6. Запрещено: фотореализм, LUT-файлы, DOF/motion blur/вигнетка/аберрация, свечение
   всего кадра, автозакрытие art-lock, изменение канона/культурного слоя.
7. Татарский текст — только через существующие text-id с пометкой «требует носителя».

## 4. Цикл проверки фазы (одинаковый для всех)

```
build → walkthrough (335,27 м PASS) → capture 48/48 PASS → осмотр кадров глазами
по чеклисту фазы и §0.1 → benchmark floor 30 → (рендерные фазы: UI-readability)
→ пары до/после в evidence/act1_prod_ready/<фаза>/ → карточка в ledger →
git diff --check → (после asset-фаз) verify-asset-registry
```

Стоп-условия: упёрся в человеческий гейт (выбор кандидатов, орнамент, art review,
татарский язык) — зафиксировать в ledger и перейти к следующей независимой фазе.

## 5. Definition of Done всего плана

- 48/48 кадров мира чисты по чеклисту Фазы 8 и бару §0.1;
- 10 UI-экранов × 2 разрешения в едином языке, readability PASS;
- ценовая 3-ступенчатая структура видна в 6 ключевых кадрах;
- тесты отключения эффектов пройдены (каждый эффект необходим);
- benchmark floor 30 с запасом; low-профиль не разваливает стиль;
- пары «до/после» всего пути в evidence; карточки фаз в ledger;
- человеческий art-gate получил висты и не заблокирован.
```
