# Ещё звуки живого зимнего села — батч 3 (04.10.2026)

Прямое поручение автора: добрать записи для восьми бытовых зимних звуков деревни:
колка дров, пиление, скрип калитки, готовка в доме, мычание коровы из сарая, детвора
в снегу, шаги по снегу и гармун. Для каждого слота — одна основная запись и, где
уместно, одна запасная.

Статус: статический подбор без запуска игры и без прослушивания (аудиовхода в этой
среде нет). Все записи — настоящие полевые/студийные записи людей, CC0; TTS и
синтеза не применялись. Данные: `/tmp/urman_sound_batch3/manifest.json`
(машиночитаемо), подготовленные файлы: `/tmp/urman_sound_batch3/prepared/`.
Этнографический контекст слотов — `06_tatar_winter_village_soundscape.md`;
уровни и общий микс — `04_mix_and_adhan_audit.md`; бюджет мотивов —
`05_lowspec_audio_plan.md`.

## Метод

1. **Поиск.** Freesound, фильтр лицензии CC0; для гармуна дополнительно поиск без
   фильтра (чтобы поймать CC BY/кандидатов с явной лицензией). Проверено 27 записей.
2. **Лицензия — только из реально отданного HTML страницы звука** (`curl -A "Mozilla/5.0"`).
   Критерий: страница содержит якорь
   `<a title="Go to the full license text" href="http://creativecommons.org/publicdomain/zero/1.0/">Creative Commons 0</a>`.
   SHA-256 каждой страницы записан в манифесте. Все 16 отобранных записей — CC0,
   атрибуция не требуется; CC BY в итог не вошёл (чистых CC0 хватило).
3. **Скачивание.** Публичные HQ-превью Freesound (MP3) — та же политика, что в уже
   поставленных батчах `sound_mood`/`village_life`; исходные WAV/FLAC для шиппинга —
   по-прежнему открытый пункт.
4. **Подготовка.** ffmpeg (на этой машине с
   `DYLD_FALLBACK_LIBRARY_PATH=/opt/homebrew/Cellar/x265/4.2/lib`) декодирует
   проверенный по sha256 источник в моно 24 кГц PCM16, берётся один непрерывный
   фрагмент (не коллаж), усиление `min(0.13/rms, 0.65/peak)`, края 20 мс, запись
   финального WAV — Python `wave`/`array`. Точно та же политика, что в
   `tools/audio/prepare_sound_mood_shots.py`. Лимит пула: ≤600 000 байт PCM,
   ≤12,5 с; у всех файлов — 81 600…303 840 байт.
5. **Проверка на заражение.** `ffmpeg -af "highpass=f=3000,volumedetect" -f null -`
   по самым тихим окнам 0,5 с и 1,0 с подготовленного клипа (искали птиц, других
   животных, музыку, речь, трассу), плюс полная полоса, огибающая RMS и чтение
   описания источника. Для непрерывных источников (кипение, детвора, пиление,
   музыка) тихих окон нет — там вывод опирается на отсутствие дискретных событий в
   огибающей и на описание. Вердикты: CLEAN / RISKY у каждого клипа ниже.
