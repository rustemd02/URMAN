# Квесты через адресную систему: аудит — 2026-10-04 (ACT1-QUEST-ADDR.1/.2/.3)

Проверено по контенту и коду; игра не запускалась. Таблица `квест/цель → как игрок узнаёт,
куда идти → маркер/автопуть → вердикт` собрана из данных, а не из пересказа.

## Структурное основание: маркеров нет по построению

- Адресная табличка сама объявляет себя не квестовым маркером:
  `AddressSignVisualComponent.cs:18` ставит мета `notQuestMarker = true`.
- Поиск по коду не находит ни `questmarker`, ни `autopath`: единственные совпадения слова
  «waypoint» — авторские точки подхода, которые передаются **физическому верификатору**
  (`Act1ConnectedWorld.Addresses.cs:49`), а не навигационному указателю.
- Цели квестов стартуют по **знанию**, а не по близости к маркеру: у всех трёх квестов
  objectives начинаются с условий `knowledge.status` (например
  `quest_marat_first_contradiction` → `compare-records` → `find-contradiction`).
- `AddressAccessVerifier` — «bounded read-only standing-body route audit against the real
  world; it neither moves the player nor opens doors or advances runtime progress»
  (`AddressAccessVerifier.cs:8-10`), то есть проверка маршрута существует и ничего не
  подсказывает игроку.

Покрытие: в реестре **27 зданий с `addressId`** (`game/content/urman.settlement.addresses.v1.json`,
например `ADR-BABAI` 17 на улице Tukay, `ADR-FAP` 2 на Urman, `ADR-MOSQUE` 23А на Tukay) и
**10 улиц**. В контенте шаблон `{address:…}` используется для шести адресов: BABAI, FAP,
MOSQUE, SHOP, SCHOOL, COUNCIL. Ни одна из трёх квестовых целей не остаётся без источника:
две опираются на адрес/документы, третья (кромка) адреса не требует, и это сказано прямо, а
не закрыто выдуманным адресом.

## Что остаётся

- Полная таблица «100 % обязательных и значимых добровольных маршрутов» требует ещё
  добровольных целей (находки, обходы, малые пространства) — их адресные источники не
  перечислены здесь, потому что не все они адресные.
- Приёмка прохода (QUEST-ADDR.4) — «источник адреса → самостоятельный поиск по табличкам» —
  воспроизводима и автоматизируется `AddressAccessVerifier`, но evidence должен быть снят на
  **текущей** сборке: это прогон, и здесь он не заявляется.
