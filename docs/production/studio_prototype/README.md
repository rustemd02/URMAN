# URMAN Studio — кликабельный прототип пяти экранов (P0)

Прототип к ТЗ [urman_authoring_studio_spec_2026-09-27.md](../urman_authoring_studio_spec_2026-09-27.md), §4.2.
Это не приложение и не принятый дизайн. Он нужен, чтобы автор проверил понятность,
плотность и размер элементов до основной реализации. Задача трекера: `STUDIO.P0`.

Открыть: `index.html` в любом браузере (без сервера и сети). Прямые ссылки на экраны:
`index.html#world`, `#trigger`, `#quests`, `#quests&graph&sel`, `#scenes`, `#merge`.

| Экран | Что проверить |
|---|---|
| Мир с каталогом | Найти «Калитку деревянную», поставить на карту, отменить (⌘Z), сохранить (⌘S). Выбрать калитку — переключить сюжетное состояние. 3D / план сверху, слои. |
| Карта + квест | Выделенный триггер «Вход во двор Тамары», почему он сейчас не сработает, связанный шаг подсвечен в квесте рядом. |
| Квесты | Сюжет / Побочные / Все / Граф. Внутри квеста — список и граф одной логики: развилка «согласиться / отказаться», параллельная группа «6 из 8», объединение. Незаконченный шаг с проблемой. «Сделать доступным после…» отдельно от перестановки. |
| Монтажная шкала | Сцена Тамары, перенесённая из `TamaraFenceCutscene.cs` в список действий и дорожки. Перемотка показывает кадр и субтитр. Ожидание неизвестной длительности. Постоянный итог при пропуске. |
| Разбор конфликта | Изменения Рустема: автообъединённые, одно поле (реплика), положение калитки, удаление против правки, порядок шагов, бинарная текстура. «Объединить» доступно после решения всех вопросов. |

Состояния из ТЗ включаются полосой «Прототип» справа внизу: пустой раздел, сбой записи
(диск заполнен), незаконченный черновик, повтор знакомства, масштаб 100–150 %.

Источники данных: реплики и ID — `content/modules/urman-chapter1/tamara-fence.json`,
планы и длительности сцены — `game/scripts/TamaraFenceCutscene.cs`. Ветка «Отказаться»,
квесты «Долг в магазине» и «Баня бабая», а также изменения «от Рустема» — вымышленные
примеры для прототипа, не канон и не существующий контент.

Не проверено человеком: визуальный дизайн, понятность новичку, плотность, размер
элементов. Это решение автора (ТЗ §24.1).
