**Статическая оптимизация — десять правок, каждая проверена сборкой без предупреждений и
ошибок** (подробности и доказательства — `performance_audit_2026-10-03.md`, пункты 6–15):

1. скаляры блока распорядка разбираются один раз, а не каждый физический тик для 33 жителей
   (≈2000 строковых поисков в секунду при 60 Гц);
2. запрос узла игрока в распорядке стал условным;
3. `AnimationCatalog.Play`/`Compatibility` находят проигрыватель через weak-таблицу, а не
   рекурсивным обходом поддерева на каждый вызов;
4. размер сетки рельефа стал `const`;
5. одиннадцать регулярных выражений разбираются один раз;
6. `Contains`/`StartsWith` — с ordinal-сравнением;
7. таблица двойников символов в `NormalizeNumber` вынесена из метода;
8. подсказка постановки строится раз на обновление предпросмотра, а не на кадр;
9. подсказки ввода кэшируются с полной инвалидацией по пяти местам правки карты ввода;
10. диагностика снега пишется только при фактической пересборке;
11. список текстовых id и запросы по префиксу кэшируются на неизменяемом репозитории;
12. `FindDescendants` — один стек вместо рекурсивного итератора (доказано 400 прогонами).

**Находки, требующие решения автора или владельца (не исправлены молча):**

- **Скольжение фактуры (R149) доказано:** шейдер выбирает пространство на материал, а одежда
  получает локальный вариант только для Alsu и CouncilWitness (Айдар и остальные — world-space),
  `ForLocalWoodPiece` вызывается лишь переносимыми предметами, поэтому двери остаются на
  world-space. Правка меняет вид и требует кадра — не внесена.
- **Баня:** дверной узел 1.70/1.80 м при капсуле игрока 1.80 → проём ≈1.68 м.
- **Кошка (R162):** авторена камнем/сланцем, у мешей нет UV, семейства меха в библиотеке нет.
- **`eng/verify-asset-registry.sh` завершается кодом 1** по шести активам (перегенерация без
  обновления реестра) — хеши не переписывал.
- **Диск 96%, ~20 ГиБ свободно**, в `/tmp` ~280 МБ чужих временных артефактов.
- **Общественные лампы без теней** (0 против 13 в доме-эталоне) — кандидат на протечку света.
- **Снежное поле:** `RefineGround` копирует `HashSet` на каждую поверхность каждый тик — первый
  адресный кандидат причины лага шагов вне дороги, нужна проверка кадром.
