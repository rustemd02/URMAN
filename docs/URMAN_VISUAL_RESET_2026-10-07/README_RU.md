# URMAN_VISUAL_RESET_PACKAGE

Пакет для Codex по полной переделке визуального языка Акта I.

**Главные файлы:**
- `START_CODEX_RU.md` — порядок чтения.
- `URMAN_FINAL_STYLE_RECIPE_RU.md` — новый визуальный контракт.
- `URMAN_VISUAL_RESTYLE_TASKS_RU.md` — единая очередь из **118** задач.
- `HANDOVER_FOR_CODEX_VISUAL_RESET.md` — полный аудит + задачи.
- `REFERENCES_RU.md` — что именно брать/не брать из каждого выбранного референса.
- `URMAN_VISUAL_REFERENCE_BOARD.pdf` — визуальный board с P1 и 15 representative reference images; физически лежит внутри ZIP.
- `ASSET_PASSPORTS_RU.md` — 18 производственных семейств ассетов.
- `AUTHOR_COMMENTS_COVERAGE_RU.md` — покрытие 40 требований автора.
- `VERIFICATION_PROTOCOL_RU.md` — доказательство результата.
- `VALIDATION_REPORT_RU.md` — структурная проверка пакета.
- `DRIVE_LINKS_RU.md` — папка Drive, ZIP и visual reference board с изображениями.

Пакет не обещает, что 118 механических галочек автоматически дадут красивую игру. Он требует human visual gates и возвращает карточки в OPEN, если фактический кадр не достиг цели.
