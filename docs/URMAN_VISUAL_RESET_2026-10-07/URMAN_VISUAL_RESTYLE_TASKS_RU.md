# УРМАН — единое строгое ТЗ на полный визуальный reset



**Это единственная исполнительная очередь пакета. Всего 118 задач: VIS-001…VIS-118.**



Правило: первые 64 карточки сохранены из прежнего аудита и дополнены новым контекстом. VIS-065–118 переводят проект на новый стиль, производят недостающие ассеты, строят visual standards и делают полный rollout.



## Как выполнять



1. Не закрывать карточку без артефакта проверки. 2. Форму исправлять раньше материала. 3. Любой новый asset — через паспорт/consumer/provenance. 4. Три эталона VIS-112–114 — промежуточный art gate, а не финал. 5. После них обязательны VIS-115–118.
