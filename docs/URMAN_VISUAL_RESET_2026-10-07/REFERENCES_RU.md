## Доставка изображений

В Google Drive создан `URMAN_VISUAL_REFERENCE_BOARD`: он содержит P1 и representative thumbnails для ключевых W/V/I/N/H кодов. Ссылка зафиксирована в `DRIVE_LINKS_RU.md`. Его экспорт `URMAN_VISUAL_REFERENCE_BOARD.pdf` физически включён в ZIP, поэтому Codex увидит изображения даже без отдельного открытия Google Doc.

В локальный пакет физически включён exact user-provided `P1`, если runtime дал доступ к файлу. Для остальных выбранных кадров сохранены коды, источники и **точное свойство**, выбранное автором. Если точные байты кадра из старого UI недоступны, это не подменяется «похожей» картинкой. Codex может открыть источник/игру для visual research, но не должен объявлять новый найденный screenshot авторски одобренным.

## Главные положительные свойства

- T1–T4 — настоящие татарские сельские фасады: конструкция, обшивка, резьба, кровельное железо, профлист и их цвет — главный ориентир для домов деревни (09.10.2026).

- P1 — painterly material surfaces без cartoon outline.
- W1 — цвет зимы.
- W2 — протоптанная дорога как форма.
- V1/V2 — смелость цветовых масс.
- V4 — линии ветра.
- I-CURRENT/I1 — сохранить интерьерный реализм, усилить цветовую температуру.
- N1/N2 — зелёная ночь и chromatic contrast.
- H2 — лесная база; H3-1 — только ветви; H4-2/H4-3 — нечеловеческие color states.
