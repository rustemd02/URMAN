## 4. Порядок исполнения и судьба существующей работы

PW0 — baseline/сценарий/карта старых функций; PW1 — kernel/книга/ввод/переходы/сохранения; PW2 — производство/материалы/память/звук/изображения; PW3 — пять миров; PW4 — деревня/наружные подтверждения/ПК/эпилог; PW5 — QA/релиз/handover. Это ориентир, реальные зависимости — `depends_on` карточки, не жёсткое ожидание конца всей фазы.

Совместимые старые игровые задачи имеют `release_role: required`, packet `LEGACY-COMPAT` и читают этот контракт первым. Повторяющиеся работы книги/вступления/материалов/ритма/приёмки привязаны к PW-преемникам как rollup: их нельзя выдавать как вторую разработку. Прежняя completion таких карточек сохранена отдельно, новый контракт переоткрыт. Прочие completed сохраняют свой прошлый результат; свежую совместимость всей деревни доказывает PW-096, а готовую сборку — REL-003.

Все 206 прежних ID имеют `integration_2026_10_08` и строку `legacy_disposition`. NARR-001 — исторический сюжетный lock; STUDIO* — отдельный продукт; REL-004 — отдельное разрешение. Это не потерянные задачи. Все карточки, включая эти потоки, видны в TASKS.md.

Выбирать dependency-ready required **work** в todo/ready/reopened либо историческом in_progress без живого владельца; blocked сначала требует доказанного снятия blocker, review — проверки, зависимости должны быть completed; среди готовых — phase/priority и эффект для игрока. Rollup закрывать только по проверенным преемникам. Старый `in_progress`/владелец из прошлой сессии не доказывает живой процесс: до выдачи проверить реальную занятость. Не перехватывать чужую работу. Импорт/сборки/защищённые запуски сериализуются. Ресурсный, станционный или человеческий blocker фиксируется на точной задаче; независимая работа продолжается.

**PW-011 выполнена только как документальный импорт.** Её прежняя зависимость PW-010 сохранена в `source_depends_on`, а документальное поручение позволило свести очередь до runtime baseline. Это не закрывает PW-001–PW-010, новый канон/стиль или какой-либо игровой PASS. У остальных новых PW runtime `NOT_RUN`, авторская приёмка `PENDING`.
