# tasktracker — единая точка входа в готовую игру УРМАН

**Параллельные рабочие блоки — 09.10.2026.** Все 306 карточек распределены по 18 блокам в [TASKS.md](TASKS.md). Основная параллель: **B01 книга + B02/B03 визуальный rework и дом + B04 нужный runtime либо другой готовый блок**. Каждый фотомир имеет свой блок; ПК, люди/язык, транспорт, звук и бытовые механики отделены. Границы, первый видимый этап и межблочные зависимости записаны в `campaign_delivery_plan.parallel_blocks` единого JSON. Общий файл имеет одного writer; станционные запуски последовательны. Готовность проверяется по карточке, а не по завершению всего блока. Живые назначения сохраняются.

**Порядок исполнения обновлён 09.10:** [короткие этапы, приоритет домов, приёмка и станция](06_small_model_execution_2026-09-22.md). В JSON читать `campaign_delivery_plan.dispatch_policy` и конкретный `execution.next_unit` выбранной карточки. Готовность по зависимостям проверяется перед назначением; этот порядок не создаёт второй очереди и не объявляет старые `in_progress` живыми работами.

Актуальный контракт — [сведение 8 октября 2026](07_full_game_integration_2026-10-08.md). Цель — законченная кампания «За краем снимка», живая Кара-Урман и **все применимые требования Visual Reset и PhotoWorlds**. Акт I и один визуальный пилот больше не ограничивают результат.

Уточнение автора 09.10: качество самих домов и окружения должно соответствовать выбранным скриншотам из референсов, включая конструкцию, детализацию, материальность и свет; одной палитры недостаточно. Существующие карточки **ACT1-DEPTH.9/10/11/12 и PW-034** содержат уточнённые критерии. Исполнителю обязательно читать [инструкцию в AGENTS.md](../../AGENTS.md) и [референс-манифест](../URMAN_VISUAL_RESET_2026-10-07/REFERENCES_RU.md); закрытие требует сопоставимых игровых кадров/движения и авторской художественной приёмки.
