**Уточнение автора 17.10 — приоритет заметного MVP.** Сначала законченные, сразу заметные игроку этапы: обычный запуск и Continue; цельный пролог и первая прогулка; фото → физическая книга → вход → содержательное действие → возврат → сохранённое продолжение; убедительная сцена деревни; самостоятельный релизный кандидат. Мелкие веточки, кусты, фактуры и локальная полировка идут после этих результатов, кроме доказанного блокера проходимости, читаемости, стабильности или производительности выбранного этапа. Порядок выдачи `ready` берётся из `campaign_delivery_plan.dispatch_policy.mvp_delivery_order` единого JSON. Проверенные этапы регулярно коммитить и пушить; обязательные критерии и внешняя приёмка сохраняются.

Принятый child завершается самостоятельно; final product требует его и обязательных внешних gates.
