# URMAN — Address & Settlement Mechanics v3

Это **mechanics-only** пакет. В нём намеренно нет готового визуала адресных табличек.

Главный принцип: **если в проекте уже есть карта деревни, не генерировать её заново**.
Сначала импортировать существующие roads/buildings/parcels, провести аудит, затем сделать минимальные логические улучшения.

## Слои данных

### 1. Physical world
- roads
- intersections
- paths
- buildings
- entrances/gates
- parcels
- forest/water/terrain constraints
- POI/landmarks

### 2. Address registry
Читаемый игроком адрес:
`Тукай ур. / ул. Тукая, 17`

Он может измениться в процессе разработки.

### 3. Stable entity registry
Квесты, сейвы и скрипты **никогда не должны ссылаться на строку адреса**.

Использовать:
- `building_id`
- `parcel_id`
- `address_id`

Эти ID не меняются при переименовании улицы или корректировке номера.

### 4. Game cadastral layer
Это правдоподобный, но **вымышленный** технический ID участка, например:

`URM-Q03-P0041`

Он вдохновлён иерархической логикой кадастрового деления, но специально не копирует реальный формат ЕГРН, чтобы в игре случайно не появлялись существующие реальные кадастровые номера.

## Pipeline для уже существующей карты

`IMPORT -> NORMALIZE -> GRAPH -> AUDIT -> PROPOSE -> APPROVE -> ADDRESS -> PARCEL IDS -> NAV -> 2D MAP`

Никаких скрытых перестроений мира.

## Pipeline если карты нет

`CONSTRAINTS -> MAIN PATH -> LOCAL ROADS -> CYCLES -> PARCELS -> BUILDINGS -> ADDRESSING`

Подробности — в `docs/`.

## Astra 6

Сначала дать Astra файл `ASTRA6_HANDOFF.md`.
Он требует:
1. найти существующую карту;
2. сохранить авторскую геометрию;
3. улучшить только доказуемо проблемные места;
4. подключить механику из этого архива;
5. только потом самостоятельно разработать визуал табличек под арт игры.

## Samples

- `sample/existing_map_input.json` — корректная уже существующая карта; pipeline её **не перестраивает**, только обогащает registry/IDs/addresses.
- `sample/broken_map_input.json` — намеренно оставленный near-miss: визуально улицы почти соприкасаются, но graph разорван.
- `sample/broken_map_audit_output.json` показывает, что система обнаруживает такую ошибку и создаёт repair proposal вместо скрытого перемещения дороги.
