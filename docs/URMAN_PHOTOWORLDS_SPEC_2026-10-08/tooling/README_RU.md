# Проверка и сборка документов

`python tooling/validate_spec.py --self-test` — стандартная библиотека Python 3.10+, без установки игровых инструментов. Проверяет целостность реестров и абстрактных графов; не запускает игру.

`python tooling/build_reading_copy.py` — собирает HTML, объединённый Markdown и PDF из профильных файлов. Требуются Python-пакеты `mistune` и `weasyprint` с системными зависимостями последнего и доступным семейством DejaVu Sans. Файлы шрифтов намеренно не включены.

Сначала редактировать `docs/`, `levels/` и `data/`, затем запускать валидатор и сборку. Сгенерированные PDF/HTML не являются отдельным источником канона. После изменения документов пересобрать контрольные суммы; исходный manifest относится только к первоначально выданному пакету.
