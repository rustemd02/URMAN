# Схемы пространственных связей

Пять SVG визуализируют графы из `data/worlds.spec.json`. Размещение узлов на рисунке топологическое, не масштабное. Метровые локальные координаты содержатся в JSON и паспорте уровня; действующие координаты деревни устанавливаются только после проверки terrain/коллизий в checkout. Пунктир показывает заданную обратимую пространственную связь, не случайный телепорт.

Схемы являются проектными документами, не скриншотами реализованной игры.
