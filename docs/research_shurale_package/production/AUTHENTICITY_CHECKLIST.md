# Контроль подлинности и согласованности

Пункты ниже — критерии проверки финальной сцены, не заявление, что игра уже реализована.

- [ ] **Регион.** Основная модель не смешана с Альметьевском без объяснения; Верхний Кумор не назван татарским.
- [ ] **Время.** У каждого заметного ремонта/прибора есть дата или статус неизвестности; Шаян ТВ не звучит в 2015.
- [ ] **Улица.** 4,5+2×(0,75+1+4)=16; пешеходная полоса не посчитана дважды.
- [ ] **Фасады.** Три фронтальных окна H02 совпадают с планом; сени не закрывают боковое кухонное окно.
- [ ] **Проходы.** Из сеней доступны остальные помещения; двери имеют место открывания; мебель не блокирует выход.
- [ ] **Двор.** Ворота совпадают с переездом; проезд не кончается в цветнике; сарай и баня доступны.
- [ ] **Инженерия.** Вода, сток, источник тепла и вентиляция не нарисованы несвязанными объектами; это не строительный проект.
- [ ] **Растения.** Локальный вид отделен от регионального списка; сорта цветов не выданы за установленный набор.
- [ ] **Сезон.** Листва, снег, вода, одежда, работы и звуки соответствуют одному состоянию.
- [ ] **Интерьер.** Музейные V003–V014 не названы современными жилыми домами.
- [ ] **Семья.** Состав обуви, посуды и спальных мест соответствует жильцам; старые вещи имеют биографию.
- [ ] **Язык.** Татарские надписи и произношение прошли носителя либо помечены как неготовые.
- [ ] **Религия.** Нет псевдоарабики и механического переноса красного угла; религиозный звук не назначен без проверки.
- [ ] **Фольклор.** S030, S031 и S033 не слиты в «древний канон»; паспорт записи не выдуман.
- [ ] **Звук.** Непрослушанное не стало прослушанным; таймкод null не заменен выдуманным; права на фонограмму оформлены.
- [ ] **Визуальный корпус.** local_path ведет к существующему файлу; внешняя ссылка не посчитана скачанной фотографией.
- [ ] **Права.** Сохранены автор, источник, лицензия и указание изменений для CC-изображений.
- [ ] **Данные.** Каждый ID уникален; ссылки на S/C/V/A/SC/G действительны; null не превратился в ноль.

## Заведомо незакрытые проверки

Натурные обмеры, действующие интерьеры, локальные растения, полевая фонограмма, разговорный татарский и первичные паспорта рассказов остаются открытыми. См. G001–G018. Проверка файла не закрывает этнографический пробел.
