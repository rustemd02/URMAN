# Звуковые материалы

В этой папке нет фонограмм: ни одна локальная полевая запись не получена и не прослушана. Атлас research/09_soundscape.md содержит 16 производственных карточек и кандидатов на проверку; data/audio_video_references.csv хранит тот же материал структурированно.

actually_listened=false; start_timecode=null; end_timecode=null. Эти значения нельзя интерпретировать как начало записи с 00:00. Ссылка на ТНВ — история вещателя, не конкретный эфир; ссылка на видео чтения — непрослушанный кандидат; страница центра традиционной культуры — институциональный путь поиска.

Перед добавлением файла нужны источник, место, дата/сезон, положение микрофона, обстоятельства съемки, точные проверенные таймкоды, сведения о монтаже и правах. Для музыки отдельно учитывать мелодию, аранжировку, исполнение и фонограмму. Отдельно хранить реальные записи и авторский голос/звуковые эффекты Шурале.
