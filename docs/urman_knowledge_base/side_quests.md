# Необязательные задания (side quests)

Обновлено: 2026-09-26.

## Как устроена система

В УРМАНе нет отдельной второй квестовой архитектуры. Необязательное задание — это обычный квест компилированного контента (`content/schemas/quest.schema.json`), у которого цель стадии не активна, пока мировое событие не перевернёт её `startConditions`. До этого квест существует в ядре, но:

- `RuntimeBridge.ActiveObjectives()` его не показывает (объектив в `pending`);
- физические интеракции задания недоступны (их `conditions` требуют того же флага);
- сохранения ничего особого не делают — состояние живёт в обычном narrative state.

Ключевые элементы переиспользованы:

| Роль | Владелец |
| --- | --- |
| Старт/прогресс/завершение | `quest/quest_*` в компилированном контенте + `QuestRuntimeCoordinator` |
| Флаги мира (гейт, счётчики) | `npc.set-state` / `npc.state` по персонажу-владельцу |
| Физическое состояние (сломан/починен, собранные места) | `world.props` через `RuntimeBridge.DispatchWorldPropsAsync` |
| Транзакции, зависящие от счёта | свой обработчик команд в `RuntimeBridge` (паттерн `shop.purchase`/`bathhouse.ignite`) |
| Постановочные сцены | отдельный director-узел, presentation-only, состояние закоммичено ДО сцены |

## quest_tamara_fence — «Забор Тамары Геннадьевны»

Необязательный мем-квест по структуре вирусного ролика «Николай Николаевич / Тамара Геннадьевна»: не цитата, а механика юмора — уважительное имя-отчество + грубое описание бытовой катастрофы + будничная реакция хозяйки.

- **Триггер**: Айдар на Ниве въезжает в авторский забор у обочины обратной улицы (участок `ReturnEastHouseA8Silhouette`, забор в ~2,2 м от оси дороги — в зоне физического досягания Нивы). Порог удара ≥ 2,2 м/с; касание забор не ломает. Событие срабатывает один раз за прохождение. Удар в бетонный столб считается ударом в забор: падает ближайший щит.
- **Забор**: бетонные столбы (0,23 × 1,86 м, светлый бетон, шапка со снегом) на белой щебневой подсыпке и между ними — деревянные щиты из шести широких горизонтальных досок, выцветших до персиково-розового, с рамой и снежной кромкой сверху. Так забор читается в исходном ролике. Столбы не падают никогда, падают только щиты.
- **Падение**: щит опрокидывается вокруг своего нижнего края (поворот узла панели), а не исчезает; ближний к удару щит падает быстрее и почти плашмя, соседние — медленнее и остаются лежать с наклоном на столбах. Отдельные доски оказываются на земле сразу, разложенные вдоль линии удара, и только слегка проскальзывают; ничего не сыплется сверху. Коллизия щита уходит вместе с ним — в проломе нет невидимой стены.
- **Транзакция аварии** (`tamara-fence.crash`): npc-флаг `tamara.fence_crashed`, мировой `tamara/fence {crashed}` и чекпоинт — одним планом ядра до начала катсцены. Выход/загрузка во время сцены не рассинхронизируют мир.
- **Катсцена** (~50 с, скип по Esc/пробелу): парень с телефоном (тело Rinat-кита с перекраской, телефон на кости `hand_r` через BoneAttachment, поза съёмки удерживается поверх живой анимации `_Process`-хуком с `ProcessPriority = 100`), Тамара Геннадьевна (тело Gulsina-кита в синей палитре исходного ролика), субтитры из контента. Камера каждого плана стоит вне корпуса Нивы и вне столбов; тайминги считаются по реальному времени, а не по кадрам. Панчлайн — «Айдар Ришатович… …расхуярил забор Тамаре Геннадьевне.» — после него 2,6 с без реплик, только реакции.
- **Поиск**: 6 целых досок в существующих местах (навес с дровами у дома бабая ×2, сарай у кромки деревни ×2, западный и восточный периметр-сараи). Подбор — контентные интеракции `tamara-fence-take-board-1..6`; место закрепляется в `world.props` и не возрождается.
- **Сдача**: интеракция у Тамары; транзакция `tamara-fence.deliver` переносит все доски при себе одним планом, диалог читает уже закоммиченный счёт (`entryRoutes` по `boards_delivered` 1..6). Промежуточные реплики — «Оставь здесь. Ещё N.»
- **Финал**: 6/6 → квест завершён, `fence_repaired`, запись в блокнот. Забор перекрашивается свежими досками, когда двор без игрока или после загрузки; обломки убираются.
- **Callback**: после ремонта медленный повторный проезд мимо на Ниве — парень молча поднимает телефон. Один раз за сессию, без текста и заданий.
- **Одна реакция деревни**: у штабеля досок у сарая парень один раз спрашивает «Доски нужны?» — «Ага.» — «Бери вон те. Они сухие.» Без продолжения.

### Канон и ограничения

- Тамара Геннадьевна и парень с телефоном — фоновые жители, не сюжетные NPC; в расследование не вмешиваются.
- Обращение «Айдар Ришатович» звучит впервые в игре; имя отца (Ришат) в канон персонажей не добавлялось — при будущей фиксации имени отца сверить (см. `open_questions.md`).
- Квест полностью обходится пешком: Нива нужна только для аварии, не для сбора/сдачи.
- Звук аварии — существующие фолей-сэмплы (`wood_tap`, `hollow_board`); отдельной записи треска досок пока нет, см. заглушки в отчёте.
