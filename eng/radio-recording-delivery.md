# Поставка записей Авыл FM

`python3 eng/apply-act1-radio-recordings.py <delivery> --dry-run` проверяет
поставку без записи в проект. Без `--dry-run` устанавливает проверенные файлы;
`--require-complete` отклоняет результат, если в программе останутся непоставленные
сегменты. Частичная поставка явно остаётся частичной. Движок и сборки скрипт не
запускает: их сериализует владелец интеграции.

В delivery должны находиться `provenance.json`, оригинальные записи, подготовленные
WAV и сохранённые первичные страницы/разрешения. Любой указанный файл обязан быть
внутри delivery и совпадать со своим SHA-256. Скрипт не создаёт звук. Тестовые
сигналы и синтез не принимаются как происхождение финальной записи станции.

```json
{
  "schemaVersion": 1,
  "stationId": "avyl-fm",
  "recordings": [
    {
      "segmentId": "music-one",
      "origin": "recorded-music",
      "file": "music-one.wav",
      "sha256": "<SHA-256 подготовленного WAV>",
      "sourceFile": "original.flac",
      "sourceSha256": "<SHA-256 оригинала>",
      "sourceURL": "https://<первичная страница именно записи>",
      "durationSeconds": 202.06933333333333,
      "language": "tt",
      "title": "<название записи>",
      "transcript": "<текст песни либо явное описание инструментальной записи>",
      "instrumental": true,
      "performer": "<исполнитель>",
      "credit": "<полная атрибуция>",
      "processing": ["<декодирование, изменение уровня/формата либо unchanged>"],
      "rights": [
        {
          "covers": ["recording", "performance", "composition", "arrangement"],
          "licenseId": "CC-BY-SA-4.0",
          "licenseURL": "https://creativecommons.org/licenses/by-sa/4.0/",
          "copyrightHolder": "<указанный лицензиар>",
          "sourceURL": "https://<первичная страница разрешения>",
          "evidenceFile": "commons-primary-source.json",
          "evidenceSha256": "<SHA-256 сохранённого свидетельства>"
        }
      ]
    }
  ]
}
```

Это форма, не утверждение о существовании или правах конкретной записи.
Для вокальной музыки обязателен также scope `lyrics`. Для разговорного сегмента
`origin` равен `human-recording`, нужны scopes `recording` и `performance`, а
`transcript` дословно совпадает с текстом действующей программы. Язык всегда
совпадает с программой; инструментальному фрагменту следует явно назначить `zxx`
в данных, если речи и пения в нём нет. Упоминание исполнителя в credits не означает,
что он поддерживает УРМАН или выступает в роли вымышленного персонажа.

Открытые лицензии, поддерживаемые валидатором: CC0 1.0, CC BY 3.0/4.0 и CC BY-SA
3.0/4.0. Права на партитуру не заменяют права на запись и исполнение. Разные
правовые слои можно описать отдельными элементами `rights`. Для иных лицензий
нужна отдельная предметная адаптация контракта; их нельзя переименовать в CC0.
При CC BY-SA производное аудио сохраняет совместимую лицензию, атрибуцию и описание
изменений. Фактическая проверка первичного источника остаётся обязательной: JSON
проверяет заявленные условия, но не удостоверяет полномочия произвольного автора
манифеста и не проводит прослушивание.

Подготовленный WAV: integer PCM, 16/24 bit, mono/stereo, 44.1/48 kHz. Длительность
должна совпадать с количеством реально прочитанных samples; разговор 0.4–180 с,
музыка 10–900 с. Проверяются целостность RIFF/chunks, отсутствие цифровой тишины,
peak ≤ −1 dBFS, RMS ≥ −45 dBFS, крайняя тишина ≤0.75 с для речи и ≤2 с для музыки.
Это технические ограничения поставки; они не принимают художественный микс,
разборчивость и произношение. Валидатор не нормализует и не обрезает аудио сам.

При установке сохраняются устойчивые ID и порядок сегментов. Длительность берётся
из WAV. Разговорные тексты не меняются; для музыки заголовок и описание приходят
из проверенной поставки. Оригиналы, манифест и свидетельства сохраняются в
`assets/source/audio/act1/radio/<sha256-provenance>/`, атрибуция также попадает в
`game/assets/audio/act1/radio/credits-<sha256-provenance>.json`. Историческая поставка
не перезаписывается. Установка использует lock, атомарную замену отдельных файлов
и откат только собственных записей при отказе; изменение станции между валидацией
и установкой отклоняется. После установки владелец интеграции обновляет asset
registry, выполняет импорт, сборку и нативный radio smoke.

`eng/fetch-radio-commons-source.py` сохраняет оригинал Commons по заранее
проверенному SHA-1, точную ревизию файловой страницы, её лицензионное объявление,
SHA-256 оригинала и первичного JSON. Он работает только в новой папке, не
подставляет файл в станцию и не меняет статус проверки.

Две финальные фразы Марата и Рината поставляются отдельно по действующему voice
brief. Станция, архивная речь и любые её тестовые fixtures их не заменяют.
