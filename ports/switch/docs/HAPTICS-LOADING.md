# Тактильный отклик и экран загрузки

Изменения выполнены в Switch-копии 05.11.2026. HapticFeedback использует Godot StartJoyVibration (weak/strong). В патч движка добавлен драйвер libnx: strong управляет амплитудой полосы 160 Гц, weak — 320 Гц. Частоты фиксированы; отдельного игрового API для частот HD Rumble нет. Реальные ощущения ещё не проверены.

По умолчанию вибрация включена, сила 50%, отклик шагов выключен. Импульсы: шаг 45 мс при фактическом контакте ноги; попытка доступного взаимодействия 55 мс; приземление зависит от скорости удара. Верхний предел любого импульса 180 мс, без бесконечных циклов. Приоритеты: тест > приземление > взаимодействие > шаг. Кулдауны ограничивают дребезг. Режим шага включается отдельно в настройках. Удар до 1,4 м/с не создаёт вибрацию.

Устройство выбирается по последнему вводу подключённого контроллера. Пауза/открытие UI, переход сеанса, загрузка, потеря фокуса и выход останавливают мотор. Дисконнект и переключение на клавиатуру/мышь снимают выбор устройства. Стоп не стирает маршрутизацию активного контроллера при обычной паузе. Поддержка событий сна/возобновления на Switch требует проверки backend.

Настройки → «Тактильный отклик»: включение, сила, опция шагов, тест. Тест использует текущие выбранные значения без сохранения; постоянная запись user://haptics.cfg выполняется при «Применить». Во время загрузки тест недоступен. Взаимодействие даёт короткий тактильный сигнал попытки, не подтверждение успешного сюжетного dispatch; открытие модального экрана может остановить его раньше.

Фон загрузки сгенерирован built-in image_gen и сохранён в game/assets/textures/ui/switch_loading_forest_v1.png. Полный промпт — reports/loading-image-prompt.txt. Изображение осмотрено. LoadingScreenUi использует фон, живые подписи, индикатор фактического прогресса ресурсов (когда загрузчик сообщает его), существующий отменяемый переход. Без данных о прогрессе используется только индикатор ожидания. Уменьшенное движение оставляет индикатор статичным, высокий контраст делает панель непрозрачной. При увеличенном тексте колонка прокручивается стрелками/крестовиной/колесом.

В этой сессии проверяется компиляция. Живые UI-кадры, фактическая вибрация и производительность на Switch не проверялись. Конфигурация предусмотренной проектом Windows test station на хосте отсутствует; локальный игровой прогон не подменял её. Остаток приёмки: 720p, увеличенный текст, отмена перехода, сохранение настроек, сила/длительность на Joy-Con, смена устройства, потеря фокуса и сон.
